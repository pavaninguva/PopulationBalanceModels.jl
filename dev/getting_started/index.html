Getting started

Installation

Extract the source archive and enter its inner PopulationBalanceModels.jl directory. Julia 1.10 or newer is required. From that directory run:

julia --project=. -e 'using Pkg; Pkg.instantiate(); using PopulationBalanceModels; Pkg.test()'
julia --project=. examples/batch_population_balance.jl

For installation into another working environment, use Pkg.develop(path="/absolute/path/to/PopulationBalanceModels.jl"). Repository URL installation is described in Publishing.

A complete population balance

This example executes when the documentation builds:

using PopulationBalanceModels

grid = Grid1D(range(0.0, 10.0; length=101); coordinate=:volume)
model = PBMModel(
    growth = Growth((v, p, t, ctx) -> p.G),
    primary = Nucleation((p, t, ctx) -> p.J, 0.0),
    loss = Death((v, p, t, ctx) -> p.k),
)
methods = TermMethods(
    growth = MUSCL(),
    by_term = (primary = BoundaryInjection(:left),),
)
operator = compile(model, grid; methods)
initial = exp.(-((grid.centers .- 2.0) ./ 0.4).^2) .* grid.widths
problem = PBMProblem(operator, initial, (0.0, 1.0);
    p=(G=0.3, J=0.05, k=0.02))
solution = simulate(problem; dt=0.01, saveat=0.0:0.25:1.0)

@assert all(isfinite, solution.u[end])
@assert minimum(solution.u[end]) >= 0.0
(number=only(moment(grid, solution.u[end], 0)),
 first_moment=only(moment(grid, solution.u[end], 1)))
(number = 0.7444460819947202, first_moment = 1.6067553690175274)

initial contains bin-integrated number concentration. Multiplying a density profile by grid.widths converts it to that representation. density performs the reverse conversion. A single-population solution stores N[bin, 1].

BoundaryInjection interprets nucleation as an inward number flux; it needs a compatible growth term and a source located at the selected domain boundary. Choose a Gaussian or pivot source method when those assumptions do not apply.
