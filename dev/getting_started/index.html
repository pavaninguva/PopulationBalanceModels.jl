Getting started

Suppose particles enter a vessel at a constant rate, grow, and are removed with a size-independent hazard. We want their size distribution after one unit of time. This small model introduces the same steps used in the case studies: define rates, choose how to discretize terms, apply boundaries, and solve.

Load the package

Use Julia 1.10 or newer. From the package checkout, run:

julia --project=. -e 'using Pkg; Pkg.instantiate(); using PopulationBalanceModels'

To work in a separate Julia environment, run Pkg.develop(path="/absolute/path/to/PopulationBalanceModels.jl") there. The remaining code blocks form one complete calculation and are executed when this manual is built.

Write the balance

Take particle volume $v$ as the internal coordinate and let $n(v,t)$ be number density per unit particle volume and process volume. In the interior,

\[\frac{\partial n(v,t)}{\partial t} +\frac{\partial[G n(v,t)]}{\partial v}=-k n(v,t).\]

Particles enter at $v=0$ with inward number flux $J$. The upper edge is closed. The constants below use a consistent arbitrary volume and time scale; the package does not convert units for us.

using PopulationBalanceModels
p = (G=0.3,J=0.05,k=0.02)

growth_rate(v,p,t,ctx) = p.G
nucleation_rate(p,t,ctx) = p.J
removal_rate(v,p,t,ctx) = p.k

model = PBMModel(
    growth = Growth(rate=growth_rate),
    primary = Nucleation(rate=nucleation_rate,size=0.0),
    loss = Death(rate=removal_rate),
)

Growth expects a coordinate velocity, not a particle flux. Death expects a nonnegative inverse-time hazard. Nucleation expects a total number creation rate and a location; its callback therefore has no size argument. The callbacks receive p, time t, and the current state context ctx, although these constant rates only need p.

Choose bins and term methods

grid = Grid1D(range(0.0,10.0;length=101);coordinate=:volume)
methods = TermMethods(
    growth = MUSCL(),
    by_term = (primary=BoundaryInjection(:left),),
)
operator = compile(model,grid;methods,bc=SizeBC(NoFlux(),NoFlux()))

MUSCL reconstructs a density for growth face fluxes. BoundaryInjection treats primary as a prescribed inward number flux at the left edge. It adds that source once, without dividing by the growth velocity. The NoFlux boundaries suppress transport through the exterior faces; the named boundary source supplies the influx separately.

The grid stores integrated bin numbers, not density samples:

\[N_i(t)=\int_{v_{i-1/2}}^{v_{i+1/2}}n(v,t)\,dv.\]

For a smooth initial profile we can use midpoint integration:

initial_density = exp.(-((grid.centers .- 2.0) ./ 0.4).^2)
initial = initial_density .* grid.widths
problem = PBMProblem(operator,initial,(0.0,1.0);p)

For discontinuities or peaks narrower than a bin, integrate the initial profile more carefully. Changing the time integrator cannot correct an inaccurate initial bin number.

Advance the solution

solution = simulate(problem;method=SSPRK33(),dt=0.01,saveat=0.0:0.25:1.0)
final = solution.u[end]
final_density = density(grid,final)
(number=only(moment(grid,final,0)),first_moment=only(moment(grid,final,1)))
(number = 0.7444460819947202, first_moment = 1.6067553690175274)

The time integrator is a separate choice from MUSCL. It sums growth, nucleation, and removal contributions at every stage. dt is a maximum step; it is shortened to reach each requested output time. A single-population solution stores bin numbers as N[bin,1]. density divides those numbers by bin widths.

A useful check follows by integrating the PDE over the closed size domain:

\[\frac{dM_0(t)}{dt}=J-kM_0(t),\qquad M_0(t)=M_0(0)e^{-kt}+\frac{J}{k}(1-e^{-kt}).\]

expected = sum(initial)*exp(-p.k) + p.J/p.k*(-expm1(-p.k))
@assert abs(sum(final)-expected) < 1e-9
@assert minimum(final) >= 0
abs(sum(final)-expected)
7.66053886991358e-15

This tests total number, while a grid-refinement study is still needed to assess the shape of the distribution. Next, Defining models explains size coordinates and state-dependent rates.
