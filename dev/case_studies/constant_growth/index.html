Comparing growth and time methods

If every particle grows at the same rate, the size distribution should move without broadening. This makes constant growth a useful test: the exact answer is known, and numerical diffusion, oscillations and computational cost can be compared without uncertainty about the physical kinetics.

We use Case 1 of Inguva, Schickel and Braatz (2022), then repeat the comparison with a smooth periodic distribution to measure convergence. The two inputs serve different purposes. A sharp front tests resolution and positivity; a smooth input tests the accuracy of the schemes.

Model, initial condition and boundaries

For $0\le a\le1$,

\[\frac{\partial f(a,t)}{\partial t} +0.1\frac{\partial f(a,t)}{\partial a}=0, \qquad f(a,0)=100\exp(-a/0.01).\]

The incoming number flux is zero. The far boundary lets particles leave; the initial tail that can reach it by $t=4$ is negligible. The analytical density is

\[f(a,t)=\begin{cases} 100\exp[-(a-0.1t)/0.01],&a\ge0.1t,\\ 0,&a<0.1t. \end{cases}\]

All numerical states are bin integrals, initialized and assessed against exact bin integrals of this function. Sampling the steep exponential only at bin centres would add a separate initialization error.

using PopulationBalanceModels
include(joinpath(pkgdir(PopulationBalanceModels),"examples","constant_growth_methods.jl"))
import .ConstantGrowthMethods
model = PBMModel(growth=Growth(AffineGrowth(0.1,0.0)))
grid = Grid1D(range(0.,1.;length=201);coordinate=:length)
bc = SizeBC(OpenBoundary(),OpenBoundary())
initial = ConstantGrowthMethods.exact_counts(grid,0.)
operator = compile(model,grid;methods=TermMethods(growth=MUSCL()),bc)
problem = PBMProblem(operator,initial,(0.,4.))
solution = simulate(problem;method=SSPRK33(),dt=0.5*first(grid.widths)/0.1)

The Courant number is $C=G\Delta t/\Delta a$. Inguva2022 requires a grid uniform in travel time and a step that moves one whole cell. For constant $G=0.1$, an ordinary uniform mesh meets that requirement:

shift_operator = compile(model,grid;evolution=Inguva2022(),bc)
shift_problem = PBMProblem(shift_operator,initial,(0.,4.))
shift_solution = simulate(shift_problem;dt=first(grid.widths)/0.1)
maximum(abs.(last(shift_solution.u).-ConstantGrowthMethods.exact_counts(grid,4.)))
1.970645868709653e-15

That $C=1$ is labelled in every comparison. It is not a valid $C=0.5$ run of the characteristic method. Its lower cost includes taking fewer steps and using a direct copy rather than reconstructing face fluxes. Other available schemes remain documented in Growth and Time integration; they have not been removed from the package.

What happens with Lax–Wendroff?

The constant-growth update is

\[\bar f_i^{m+1}=\bar f_i^m -\frac{C}{2}(\bar f_{i+1}^m-\bar f_{i-1}^m) +\frac{C^2}{2}(\bar f_{i+1}^m-2\bar f_i^m+\bar f_{i-1}^m).\]

It is selected as a complete space–time method:

operator = compile(model,grid;evolution=LaxWendroff(),bc)
solution = simulate(PBMProblem(operator,initial,(0.,4.));
    dt=0.5*first(grid.widths)/0.1,check_nonnegative=false)

The audit compares its interior coefficients with model_1.m in PBM_Schemes. The updates agree to roundoff when supplied the same numerical values. Repeating the reference stencil on 201 nodes at $C=0.5$ gives a minimum density near $-16.09$; it also produces negative lobes. The paper's Figure 1 uses $C=1$, where the update reduces to a one-cell shift and this particular error disappears.

At $C=0.5$ these are bounded dispersive oscillations. For periodic advection, the Fourier amplification satisfies

\[|A(\theta)|^2=1-4C^2(1-C^2)\sin^4(\theta/2)\le1, \qquad |C|\le1.\]

Stability does not imply a nonnegative density. The runner retains negative values so their size is visible; a checked physical solve should use a suitable positivity-preserving method when these undershoots are unacceptable.

There are also two differences to account for when comparing entire runs:

  • The MATLAB solver evolves nodal values, uses a zero left ghost and a reflected right ghost. The package evolves bin integrals with a prescribed zero total inlet flux and an advective outlet. Those boundary updates are distinct.
  • The MATLAB loop keeps its nominal step and can finish beyond the requested final time. For 200 nodes at nominal $C=1$ it ends near 4.0201. The package lands on 4 by shortening the last step, which then has $C<1$ and loses the exact-shift cancellation. Using aligned meshes and output times avoids that mismatch. The grids in this comparison are aligned.

These findings do not support changing the interior Lax–Wendroff coefficients. They explain why a $C=0.5$ or unaligned-output result should not be compared with the paper's whole-cell $C=1$ result as if they were the same calculation. The audit CSV records both boundary treatments, requested/actual times, minima and coefficient differences.

Compare both error norms

For analytical bin averages $\bar f_i^{\mathrm{exact}}$, we report

\[E_{L^1}=\sum_i\Delta a_i\left|\bar f_i-\bar f_i^{\mathrm{exact}}\right|, \qquad E_{\mathrm{RMS}}=\left[ \frac{\sum_i\Delta a_i(\bar f_i-\bar f_i^{\mathrm{exact}})^2} {a_{\max}-a_{\min}}\right]^{1/2}.\]

The front is discontinuous, so these curves do not establish formal smooth-solution order. The companion calculation uses periodic boundaries and

\[f(a,0)=1+0.2\sin(2\pi a)+0.1\cos(4\pi a), \qquad f(a,t)=f(a-0.1t,0)\]

with periodic continuation. Both initialization and comparison again use exact bin integrals.

Rather than placing arbitrarily anchored $h^2$ and $h^5$ lines on these plots, we calculate the observed order from each pair of grids:

\[p_{\mathrm{obs}}= \frac{\log[E(N)/E(2N)]}{\log2}.\]

Upwind approaches first order and Lax–Wendroff second order. MUSCL approaches second order in $L^1$ but about 1.8 in RMSE here, because limiting near smooth extrema affects the norms differently. WENO5 with SSPRK33 approaches third order as time error dominates. RK4 gives much smaller errors on this mesh range; its observed slopes above five are finite-range behaviour, not proof of a new order or of fifth-order space–time accuracy. At sufficiently fine resolution, fourth-order temporal error can dominate that pairing too. The characteristic shift is at roundoff, where an inferred convergence order is meaningless.

Measure computation time once

Each configuration has one measured integration. Small, separate warmups compile the method before measuring; the benchmark-sized problem is not run three times. Timings include stepping, residual evaluation and allocations, and exclude compilation, file output and plotting. They have no averaging or repeatability bands and will vary between runs and machines.

Raw results are in errors.csv and smooth_errors.csv. They also retain negative number, total-number drift and actual step counts.

julia --project=. examples/constant_growth_methods.jl
julia --project=. examples/audit_lax_wendroff.jl
python docs/benchmarks/plot_transport_comparisons.py constant --usetex
julia --project=docs docs/make.jl

Growth and timing comparison

module ConstantGrowthMethods
using PopulationBalanceModels

const growth=0.1
initial_density(a)=a>=0 ? 100exp(-a/0.01) : 0.0
primitive(a)=a<=0 ? 0.0 : -expm1(-a/0.01)
function exact_counts(grid,t)
    [b<=growth*t ? 0.0 : exp(-max(a-growth*t,0)/0.01)*
        (-expm1(-(b-max(a,growth*t))/0.01))
        for (a,b) in zip(grid.edges[1:end-1],grid.edges[2:end])]
end
function smooth_counts(grid,t)
    a=grid.edges[1:end-1].-growth*t;b=grid.edges[2:end].-growth*t
    grid.widths.+0.2.*(cos.(2pi.*a).-cos.(2pi.*b))./(2pi).+
        0.1.*(sin.(4pi.*b).-sin.(4pi.*a))./(4pi)
end

# A small set separates space, time and a complete characteristic update.
combinations()=[
    ("upwind","euler",Upwind(),ForwardEuler()),
    ("muscl","ssprk33",MUSCL(),SSPRK33()),
    ("weno5","ssprk33",WENO5(),SSPRK33()),
    ("weno5","rk4",WENO5(),RK4()),
    ("lax_wendroff","coupled",nothing,LaxWendroff()),
    ("inguva2022","coupled",nothing,Inguva2022())]

function make_problem(grid,initial,scheme,time,tf,bc)
    model=PBMModel(growth=Growth(AffineGrowth(growth,0.0)))
    op=scheme===nothing ? compile(model,grid;evolution=time,bc) : compile(model,grid;growth_scheme=scheme,bc)
    PBMProblem(op,initial,(0.,tf))
end
function measure(grid,initial,truth,scheme,time,tf,dt,bc)
    problem=make_problem(grid,initial,scheme,time,tf,bc)
    # Exactly ONE measured solve. Small, separate warmups below compile the
    # method without repeating every benchmark-sized calculation.
    timed=@timed simulate(problem;method=time,dt,check_nonnegative=false)
    solution=timed.value;N=vec(last(solution.u));f=density(grid,N);error=density(grid,N.-truth)
    (;N,f,rmse=sqrt(sum(error.^2 .*grid.widths)/sum(grid.widths)),
        l1=sum(abs.(error).*grid.widths),maximum_error=maximum(abs.(error)),
        minimum_density=minimum(f),negative_number=-sum(min.(N,0)),
        number_drift=sum(N)-sum(initial),seconds=timed.time,steps=solution.steps)
end

function run(;grids=(50,100,200,400,800,1600),smooth_grids=(40,80,160,320,640),
        courants=(0.5,1.0),tf=4.,output=joinpath(@__DIR__,"..","docs","src","assets","constant_growth"))
    mkpath(output);choices=combinations()
    # Compile each scheme on a tiny grid for BOTH boundary classes. Timings
    # then describe stepping/allocation, not Julia's first-call compilation.
    for (_,_,scheme,time) in choices,periodic in (false,true)
        g=Grid1D(range(0.,1.;length=21));dt=(time isa Inguva2022 ? 1. : .5)/(20growth)
        bc=periodic ? SizeBC(Periodic(),Periodic()) : SizeBC(OpenBoundary(),OpenBoundary())
        simulate(make_problem(g,exact_counts(g,0.),scheme,time,dt,bc);dt,check_nonnegative=false)
    end
    open(joinpath(output,"errors.csv"),"w") do io
        println(io,"scheme,time_method,courant,bins,rmse,l1,max_error,minimum_density,negative_number,number_drift,seconds,steps")
        for n in grids,C in courants,(name,tname,scheme,time) in choices
            name=="inguva2022" && C!=1. && continue
            g=Grid1D(range(0.,1.;length=n+1);coordinate=:length);truth=exact_counts(g,tf)
            # A common zero-inflow/open-outflow condition; initial outgoing tails
            # are negligible at t=4. Characteristic transport requires this pair.
            result=measure(g,exact_counts(g,0.),truth,scheme,time,tf,C/(n*growth),SizeBC(OpenBoundary(),OpenBoundary()))
            println(io,join((name,tname,C,n,result.rmse,result.l1,result.maximum_error,
                result.minimum_density,result.negative_number,result.number_drift,result.seconds,result.steps),','))
            if n==200
                open(joinpath(output,"$(name)_$(tname)_$(C)_$(n).csv"),"w") do data
                    println(data,"size,density,exact")
                    for i in eachindex(result.f);println(data,join((g.centers[i],result.f[i],truth[i]/g.widths[i]),','));end
                end
            end
        end
    end
    open(joinpath(output,"smooth_errors.csv"),"w") do io
        println(io,"scheme,time_method,bins,dt,courant,rmse,l1,observed_rmse_order,observed_l1_order,seconds,steps,minimum_density,number_drift")
        for (name,tname,scheme,time) in choices
            old_rms=NaN;old_l1=NaN;old_n=0
            for n in smooth_grids
                g=Grid1D(range(0.,1.;length=n+1));C=name=="inguva2022" ? 1. : .5;dt=C/(n*growth)
                result=measure(g,smooth_counts(g,0.),smooth_counts(g,tf),scheme,time,tf,dt,SizeBC(Periodic(),Periodic()))
                qr=name!="inguva2022" && isfinite(old_rms) ? log(old_rms/result.rmse)/log(n/old_n) : NaN
                ql=name!="inguva2022" && isfinite(old_l1) ? log(old_l1/result.l1)/log(n/old_n) : NaN
                println(io,join((name,tname,n,dt,C,result.rmse,result.l1,qr,ql,result.seconds,result.steps,result.minimum_density,result.number_drift),','))
                old_rms=result.rmse;old_l1=result.l1;old_n=n
            end
        end
    end
    write(joinpath(output,"inputs.txt"),
        "Inguva et al. (2022), Case 1 Eq.56: g=.1, f0=100exp(-a/.01), domain [0,1], tf=$tf.\n"*
        "All errors compare analytical bin integrals. Zero inflow/open outflow; far-boundary exponential tail is negligible.\n"*
        "Smooth check: f0=1+.2sin(2πa)+.1cos(4πa), periodic [0,1].\n"*
        "Six representative pairings. Common C=.5; Inguva2022 requires C=1 and is labelled separately. Front profiles also compare C=1.\n"*
        "One measured solve per configuration, following tiny separate compilation warmups. No timing medians, repeated production runs or timing bands.\n"*
        "Observed L1 and RMSE orders are measured from successive grids; no fitted or arbitrarily anchored order-guide lines.\n"*
        "Signed density minima and number drift retained. Julia $(VERSION); CPU $(Sys.CPU_NAME).\n")
    println("Growth comparison written to ",output)
end
if abspath(PROGRAM_FILE)==@__FILE__;run();end
end

Lax–Wendroff audit

module LaxWendroffAudit
using PopulationBalanceModels
export reference_step,run_audit

# Independently expand the three coefficients of the MATLAB model_1.m update.
# This is a nodal stencil with zero left ghost and a reflected right ghost.
# It is used for verification, not as a replacement for conservative FV fluxes.
function reference_step(f,C)
    a=C*(C+1)/2;b=1-C^2;c=C*(C-1)/2
    out=similar(f)
    out[1]=b*f[1]+c*f[2]
    for i in 2:length(f)-1;out[i]=a*f[i-1]+b*f[i]+c*f[i+1];end
    out[end]=(1-C^2)*f[end]+C^2*f[end-1]
    out
end

function run_audit(;output=joinpath(@__DIR__,"..","docs","src","assets","constant_growth"))
    mkpath(output)
    open(joinpath(output,"lax_wendroff_audit.csv"),"w") do io
        println(io,"method,courant,points,requested_time,actual_time,minimum_density,maximum_density,interior_step_difference")
        for C in (.5,1.),points in (200,201)
            dx=1/(points-1);dt=C*dx/.1;f0=100 .*exp.(-collect(range(0.,1.;length=points))./.01)
            steps=ceil(Int,4/dt-.001) # MATLAB loop stopping rule, not a shortened last step
            f=copy(f0)
            for _ in 1:steps;f=reference_step(f,C);end
            # Feed identical numerical values into the FV update. Only the
            # interior stencil is compared; nodal and FV boundaries differ.
            g=Grid1D(range(0.,points*dx;length=points+1))
            op=compile(PBMModel(Growth(AffineGrowth(.1,0.))),g;evolution=LaxWendroff(),bc=SizeBC(OpenBoundary(),OpenBoundary()))
            pb=PBMProblem(op,f0.*dx,(0.,4.))
            firststep=vec(simulate(remake(pb;tspan=(0.,dt));dt,check_nonnegative=false).u[end])./dx
            difference=maximum(abs.(firststep[2:end-1].-reference_step(f0,C)[2:end-1]))
            println(io,join(("reference_nodal",C,points,4.,steps*dt,minimum(f),maximum(f),difference),','))
            # A separate physical FV run uses exact initial bin integrals and
            # lands exactly on the requested time.
            N0=exp.(-g.edges[1:end-1]./.01).*(-expm1.(-g.widths./.01))
            out=simulate(PBMProblem(op,N0,(0.,4.));dt,check_nonnegative=false)
            d=vec(last(out.u))./g.widths
            println(io,join(("package_finite_volume",C,points,4.,last(out.t),minimum(d),maximum(d),difference),','))
        end
    end
end
if abspath(PROGRAM_FILE)==@__FILE__;run_audit();end
end
