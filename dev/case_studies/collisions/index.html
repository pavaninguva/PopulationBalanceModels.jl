Aggregation and breakage

Physical question and event equations

Aggregation merges particles and breakage creates daughters. For additive size, their moment rates are

\[\frac{dM_k}{dt}\big|_A=\tfrac12\iint[(x+y)^k-x^k-y^k]K(x,y)n(x)n(y)\,dx\,dy,\]

\[\frac{dM_k}{dt}\big|_F=\int a(x)n(x)\left[\sum_j\nu_jx_j^k-x^k\right]dx.\]

These conserve $M_1$ when daughter properties sum to the parent's and products remain represented. Number is not conserved: each binary aggregation event reduces it by one, while equal binary fragmentation increases it by one.

Implementation and numerical choices

Run examples/aggregation_and_breakage.jl. A volume grid has pivots 1 through 40. Initially pivot 4 contains unit number concentration. The constant aggregation kernel is 0.03 and particles of size at least 2 split with hazard 0.02 into two daughters of size $x/2$. Both mechanisms use fixed pivot and explicitly discard unresolved products. SSPRK33 uses dt=0.01 over one time unit.

Results and interpretation

The script prints initial/final resolved first moments and instantaneous unresolved birth rates. Any first-moment loss must be interpreted with those truncation rates; they are not cumulative loss totals. Increase the size range or integrate a reservoir before claiming a closed material balance. The scientific tests check identical-pair factors, daughter multiplicity, and nonuniform-grid conservation. They do not imply a general positivity guarantee for arbitrary kernels and time steps. The numerical manual derives deposition weights and diameter-space volume conservation.

Numerical output

On Julia 1.10.3, the resolved first moment changed from 4 to 3.9999999999999787. The final unresolved property birth rate was about 2.18e-16, negligible for this particular initial state and horizon.

Executable source

This listing is read directly from the runnable script during the documentation build.

Source on GitHub

using PopulationBalanceModels

grid=Grid1D(0.5:1.0:40.5;coordinate=:volume)
aggregation=Aggregation((v,w,p,t,ctx)->p.K;overflow=:discard)
breakage=Breakage((v,p,t,ctx)->v>=2 ? p.b : 0,
    (v,p,t,ctx)->((v/2,2.0),);overflow=:discard)
op=compile(PBMModel(aggregation+breakage),grid)
initial=zeros(length(grid)); initial[4]=1
problem=PBMProblem(op,initial,(0.0,1.0);p=(K=0.03,b=0.02))
solution=simulate(problem;dt=0.01,saveat=[0.0,1.0])
println("Initial/final resolved first moments: ",
    (sum(grid.centers.*initial),only(moment(grid,solution.u[end],1))))
println("Final unresolved birth rates: ",diagnostics(op,solution.u[end],problem.p,1.0))
# These are instantaneous loss rates, not cumulative overflow reservoirs.
# To close a time-integrated balance, integrate the rates with consistent
# quadrature, or add explicit reservoirs in a future ledger implementation.
