Interacting populations and shared solute

Physical question and balances

A precursor population nucleates from a shared solute pool and transfers to a product population. Can their numerical representations differ while preserving material? With source size 2, $J=kc$, and transfer hazard $r$, the continuum bookkeeping is

\[\partial_t n_A=kc\,\delta(x-2)-rn_A,\qquad \partial_t n_B=rn_A,\qquad \dot c=-2kc.\]

The conserved quantity is $c+M_{1,A}+M_{1,B}$, assuming common additive size units and no truncation. Solute concentration is expressed in that same particle-property concentration basis.

Implementation and numerical choices

Run examples/interacting_populations.jl. It compiles a uniform precursor grid and a nonuniform product grid, then adds PopulationTransfer and ConservativeExchange to PBMSystem. Initially both populations are empty and $c=5$; $k=0.1$ and $r=0.3$. SSPRK33 advances all states with dt=0.01 to time 3. Pivot deposition transfers particles across the two grids; the exchange uses the actual selected nucleation residual.

Results and interpretation

The script reports free solute, both population numbers, and total material. The total should remain close to 5 within floating-point/integration error. Transfer changes population identity without consuming solute a second time. Check number and property conservation separately if adding fragmentation, a destination-size map, or a nonunit transfer multiplicity. The coupling manual supplies a complete executed model and explains unlike-population collisions and moment-based bulk exchange.

Numerical output

On Julia 1.10.3, final solute was 2.7440581799, precursor number 0.7112098833, and product number 0.4167610268; total material was 4.999999999999909.

Executable source

This listing is read directly from the runnable script during the documentation build.

Source on GitHub

using PopulationBalanceModels

gridA=Grid1D(0.5:1:10.5)
gridB=Grid1D([0.5,1.5,3.5,5.5,8.5,11.5])
A=compile(PBMModel(Nucleation((p,t,ctx)->p.k*ctx.bulk.c,2.0)),gridA)
B=compile(PBMModel(),gridB)
system=PBMSystem((precursors=A,products=B);
    interactions=(PopulationTransfer(:precursors,:products,(x,p,t,ctx)->p.transfer),),
    exchanges=(ConservativeExchange(:precursors,:c,(x,p,t,ctx)->x),),
    nonnegative_bulk=(:c,))
problem=PBMProblem(system,(precursors=zeros(length(gridA)),products=zeros(length(gridB))),
    (0.0,3.0);bulk0=(c=5.0,),p=(k=0.1,transfer=0.3))
solution=simulate(problem;dt=0.01,saveat=0:0.25:3)
final=stateview(problem,solution.u[end])
println("Final dissolved concentration: ",final.bulk.c)
println("Precursor/product numbers: ",(sum(final.populations.precursors),sum(final.populations.products)))
println("Conserved total: ",final.bulk.c+moment(gridA,final.populations.precursors,1)+moment(gridB,final.populations.products,1))
