Estimating kinetic parameters

Physical question and analytical data

Can a common first-order removal hazard be recovered from two experiments with different initial concentrations? For $\partial_t n=-kn$, total number obeys $M_0(t)=M_0(0)e^{-kt}$. The example generates data analytically with $k=0.4$ at times 0, 0.2, 0.6, 1.2, and 2, for initial scales 1 and 2. This independent formula avoids generating synthetic data with the same numerical solver used in the fit. Standard deviation 0.02 defines the illustrative likelihood; the observations contain no random noise.

Implementation and numerical choices

Run examples/estimate_kinetic_parameters.jl in a working environment containing this package and Optim (see the developer guide). The script compiles a Death-only model, uses MomentObservable(0), constructs two Experiments, and fits the common parameter through k=exp(z[1]). The initial guess is 0.15. The forward reference solver uses dt=0.01 and Optim is limited to 100 iterations.

Results and interpretation

The script prints the fitted physical hazard, optimizer convergence, local residual-Jacobian rank, and covariance. A fit near 0.4 checks this synthetic inverse problem and the optional extension. Full local rank distinguishes its single parameter locally; it does not prove that a multimechanism PBM can identify all its rates. The covariance is in log-rate coordinates and assumes the declared Gaussian observation errors. Repeat with refined integration and realistic noise before interpreting uncertainty. Joint bulk, number, and PSD measurements can constrain different mechanisms, as explained in Observations and estimation.

Numerical output

On Julia 1.10.3 with Optim 2.3.1, the fitted hazard was 0.3999999989, the optimizer converged, and the local Jacobian rank was one. The reported log-rate covariance was approximately 0.000310686.

Executable source

This listing is read directly from the runnable script during the documentation build.

Source on GitHub

using PopulationBalanceModels, Optim

# Install Optim in the active working environment to enable PopulationBalanceModels's fit extension.
# Data are analytical, independent of the implementation used for fitting.
grid=Grid1D(range(0,8;length=41))
model=PBMModel(Death((v,p,t,ctx)->p.k))
op=compile(model,grid)
initial=exp.(-grid.centers).*grid.widths
times=[0.0,0.2,0.6,1.2,2.0]
experiments=Experiment[]
for scale in (1.0,2.0)
    problem=PBMProblem(op,scale*initial,(0.0,2.0);p=(k=0.4,))
    data=scale*sum(initial).*exp.(-0.4.*times)
    observation=Observation(times,data,MomentObservable(0);sigma=0.02)
    push!(experiments,Experiment(problem,observation))
end
calibration=CalibrationProblem(experiments;
    parameters=(z,experiment)->(k=exp(z[1]),),dt=0.01)
result=fit(calibration,[log(0.15)];maxiters=100)
report=sensitivity_report(calibration,result.minimizer)
println("Estimated k: ",exp(result.minimizer[1]))
println("Optimizer converged: ",result.converged)
println("Local residual-Jacobian rank: ",report.rank)
println("Local covariance is in log(k) coordinates: ",report.covariance)
