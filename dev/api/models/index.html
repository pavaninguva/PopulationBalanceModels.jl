Models and representations

Terms describe physical mechanisms; their rate functions describe dependence on coordinates, parameters, time and the current context. Grids store bin integrals. MomentSet specifies a moment basis, while the chosen moment method determines the solver state. Boundary conditions and declared growth-law structure also belong to the model specification.

Start with Defining models. For a complete program, see Getting started; for numerical policy choices, see Numerical methods.

PopulationBalanceModels.AbsorbingZero — Type

Absorbing physical zero-size boundary. Only valid on the left edge at zero; outgoing number disappears and carries zero material for positive powers of size. The sectional closure uses the first-cell density for the outgoing trace.

source
PopulationBalanceModels.InflowFlux — Type

An inward number flux rate(p,t,ctx) at a size boundary, independent of G.

source
PopulationBalanceModels.MomentBoundary — Type
MomentBoundary(; lower=0.0, upper=Inf, left=:error, right=:error)

Declared support and characteristic boundary treatment for MeasureEuler. :absorb is allowed only at physical zero on the left; :escape records removal at a finite computational edge; :error rejects a crossing. Atomic particles are removed at their hitting time, without inferring a continuum density trace. Residual-based moment solvers do not implement these boundary events.

source
PopulationBalanceModels.NoFlux — Type

Zero external number flux. With SizeDiffusion this prescribes total G*n - ∂_L(D*n) = 0; it is not a prescribed boundary density. An explicitly selected BoundaryInjection replaces the zero total flux by its birth flux.

source
PopulationBalanceModels.OpenBoundary — Type

Allow outward flux; impose zero distribution on incoming characteristics.

source
PopulationBalanceModels.AffineGrowth — Type
AffineGrowth(offset, slope)

Autonomous size law G(a)=offset+slope*a. Each coefficient is a finite number or a Symbol naming a parameter in p. This declaration rules out hidden time, bulk-state and cross-coordinate dependence and permits compilation of the Inguva transformation methods. Ordinary Growth/Growth2D callbacks remain valid for the residual-based schemes.

source
PopulationBalanceModels.ConstantKernel — Type

A size-independent aggregation coefficient; may depend on parameters/state/time.

source
PopulationBalanceModels.ExponentialGrowth — Type
ExponentialGrowth(amplitude, exponent)

Autonomous law G(x)=amplitude*exp(exponent*x). Coefficients are finite numbers or parameter names, as in AffineGrowth. HOC checks positivity on the domain.

source
PopulationBalanceModels.HOCGrowthLaw — Type
HOCGrowthLaw(rate; lower_bound, dependencies=(:coordinate,:parameters), periodic=false)

Declare a smooth (C⁶), strictly positive directional law rate(x,p,t,ctx) for HOC. lower_bound(p,t,ctx) must be a positive lower bound on the entire compiled axis at that time. periodic=true additionally declares a smooth periodic extension, including derivatives. These assumptions are supplied by the user; sampling does not certify them. HOC checks the bound and every numerical face value on problem construction and every update. Allowed dependencies are the own :coordinate, :time, :parameters, and prescribed :fields.

source
PopulationBalanceModels.MomentSource — Type

Source raw moment rate(p,t,ctx)*rawmoment(k,p,t,ctx). rawmoment is the kth moment per created particle (including k=0). Use this to specify the integral of a distributed source explicitly, rather than reconstruct it from population quadrature nodes. A boundary birth at zero is Nucleation(rate,0.0).

source
PopulationBalanceModels.PolynomialRate — Type

Polynomial a₀+a₁x+…; each coefficient is numeric or a (p,t,ctx) callback.

source
PopulationBalanceModels.PrescribedRate — Type
PrescribedRate(callback; dependencies=(:time, :parameters))

Declare a smooth prescribed (p,t,ctx) rate, independent of the evolving population and bulk states. Allowed dependencies for HOC are :time, :parameters, and prescribed :fields. This is a user contract, not a proof. For a 2D HOC incoming face flux it denotes flux density per transverse size; the solver integrates it over each transverse bin. It must be uniform along that face. Ordinary unwrapped callbacks remain supported by residual methods.

source
PopulationBalanceModels.SelfSimilarDaughters — Type

Expected daughters (ratio*parent,count) with a declared conserved power.

source
PopulationBalanceModels.SeparableGrowth2D — Type
SeparableGrowth2D(xlaw, ylaw)

Declare independent directional laws G₁(a₁,p,t) and G₂(a₂,p,t). Each solver validates the constituent laws: characteristic shifts require autonomous AffineGrowth; HOC also accepts ExponentialGrowth, TimeScaledGrowth and declared HOCGrowthLaw instances. Cross-coordinate and evolving bulk dependence are excluded from those direct solvers.

source
PopulationBalanceModels.TimeScaledGrowth — Type
TimeScaledGrowth(law, factor::PrescribedRate)

Positive prescribed modulation of an autonomous spatial law. HOC evaluates the factor at the midpoint of each full time step, without an autonomous G*f transformation. No population or evolving bulk feedback is supported.

source
PopulationBalanceModels.UniformVolumeDaughters — Type
UniformVolumeDaughters(;quadrature_order=12)

Binary fragmentation uniform in daughter volume, expressed in a length coordinate: b(x|y)=6x²/y³ for 0<x<y. The integral is two expected daughters; the third length moment is conserved. Use AdditiveCoordinate(x->x^3,cbrt). Moment rules integrate each daughter moment analytically; sectional rules use positive Gauss–Legendre daughter counts before conservative fixed-pivot deposition. These are fragments of one event, not probability weights.

source
PopulationBalanceModels.daughter_moment — Function
daughter_moment(law,parent,k,p,t,ctx)

Optional analytical integral ∫x^k b(x|parent)dx per breakage event. Extend it for a daughter law to avoid inner quadrature in moment weak forms. The law must also supply its ordinary positive daughter quadrature for validation/sectional use, conserving the declared additive measure. UniformVolumeDaughters supplies 6parent^k/(k+3). This is an expected-count moment, not a normalized probability.

Bin-integrated number source integral(lo,hi,p,t,ctx) per time.

PopulationBalanceModels.IntegratedNucleation — Type
IntegratedNucleation(rate, fraction; normalization=:total_rate)

fraction(lo,hi,p,t,ctx) integrates a nonnegative source shape over a bin. :total_rate renormalizes on the resolved domain so sum(dN)=rate. :density_amplitude uses the supplied bin integrals without renormalization. For a physical probability density this preserves the fraction inside the domain.

PopulationBalanceModels.GaussianNucleation — Method
GaussianNucleation(rate; center, width, truncation=:renormalize)

One-dimensional Gaussian creation with bin-integrated weights. center and standard-deviation width are numbers or (p,t,ctx) callbacks. :renormalize creates the full rate on the finite domain; :physical retains only the physical Gaussian fraction inside that domain. Width is a physical model parameter, independent of grid spacing.

PopulationBalanceModels.Growth — Type
Growth(rate)
Growth(; rate)

Conservative transport in the internal coordinate x, with PDE contribution $-\frac{\partial (Gn)}{\partial x}$. Supply rate(x,p,t,ctx) -> G in coordinate units per time; this is a velocity, not a particle birth rate or a precomputed face flux. The callback is evaluated at grid faces and at the current integration stage. Select Upwind/MUSCL/WENO5 separately through TermMethods(growth=...). For eligible homogeneous growth, declare AffineGrowth and select the complete Inguva2022 transport update with compile(...; evolution=Inguva2022(),p).

source
PopulationBalanceModels.Nucleation — Type
Nucleation(rate, size)
Nucleation(; rate, size)

Point creation J*δ(x-size), where rate(p,t,ctx) -> J is total number per process-volume per time and size is a fixed location in the grid's coordinate (not necessarily an additive property). The default FixedPivot method requires a location inside the pivot range. For an edge source select BoundaryInjection explicitly; for a physical size spread use GaussianNucleation. Do not add the same creation event again as an InflowFlux boundary.

source
PopulationBalanceModels.SizeDiffusion — Type
SizeDiffusion(D)
SizeDiffusion(; diffusivity=D)

Random-fluctuation growth-rate dispersion in one internal coordinate L: $∂ₜn = ∂²_L(D n)$. Together with Growth the total flux is $F = G n - ∂_L(D n)$ (Ito/Fokker–Planck convention), not Fickian $-D ∂_L n$ for size-dependent D. D is a finite nonnegative constant or a pure callback D(L,p,t,ctx) in coordinate²/time, evaluated at bin centres using the current integration-stage context, including ctx.bulk.

On Grid2D, supply (Dx,Dy) constants or D((x,y),p,t,ctx) returning that pair. A scalar means equal diagonal coefficients (compatible coordinate units required). The PDE contribution is ∂xx(Dx*n)+∂yy(Dy*n): independent coordinate fluctuations, with no mixed derivative or cross-covariance. Coefficients may depend on both coordinates and the current bulk state. Matrices are rejected.

Supports residual-based Grid1D/Grid2D sectional populations, standalone or in PBMSystem, on uniform/nonuniform rectangular meshes with NoFlux at both ends or paired Periodic ends on each axis. The default FiniteVolumeDiffusion acts on bin densities Nᵢ/widthᵢ. Select it with TermMethods(size_diffusion=FiniteVolumeDiffusion()). BoundaryInjection adds one prescribed total number flux in 1D, including without Growth. Tensor point sources use Nucleation2D's fixed-pivot/Gaussian methods; tensor boundary injection is unavailable. Other size boundaries, moment/axial representations and direct evolution are unsupported. Use suggest_dt for the combined explicit growth/diffusion/loss recommendation; it does not automatically control simulate's timestep.

source

Grid1D(edges; coordinate=:volume)
