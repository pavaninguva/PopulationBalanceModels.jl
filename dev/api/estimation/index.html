Parameter estimation

Bayesian estimation shares one statistical model across MAP, uncertainty and sampling. Priors declare their density coordinates; transforms and Jacobians remain part of that target. Full-Hessian Laplace and sensitivity-based Gauss–Newton approximations have separate assumptions and diagnostics. The older Gaussian-calibration and deterministic-discrepancy interfaces retain their distinct interpretations.

Begin with the complete first MAP fit. The estimation guide covers likelihoods, derivatives, profiles, posterior sampling and prediction budgets. Eligible stationary models use the same interfaces through StationarySolver.

PopulationBalanceModels.LaplaceApproximation — Type

Joint local Gaussian approximation of the z posterior, with the full negative-log-posterior Hessian and its factorization; includes all nuisance parameters.

PopulationBalanceModels.LaplaceFailure — Type

Failure of a Laplace calculation; report retains curvature, weak directions and the reason. No ridge/jitter is added.

PopulationBalanceModels.PosteriorSamples — Type

MCMC draws stored as (parameters, retained draws, chains), physical values and sampler diagnostics. Inspect diagnostics before using draws for inference.

PopulationBalanceModels.check_gradient — Method

Verify the selected gradient against independent step-halved central differences at a specified z. Local agreement does not establish global smoothness of limiter or mesh branches.

source
PopulationBalanceModels.diagnostics — Method

Return the sampler report, including rank R-hat, bulk/tail ESS, MCSE, per-chain energy/BFMI and adaptation statistics. A passed screen is evidence to assess, not a proof of convergence.

source
PopulationBalanceModels.identifiability_report — Method

Likelihood-only local prediction sensitivities/SVD and observed curvature, reported separately from prior curvature. Prediction rank alone omits information in inferred noise/covariance parameters; observed likelihood curvature includes it. Neither establishes global identifiability.

source
PopulationBalanceModels.laplace_approximation — Method
laplace_approximation(problem,map;step, hessian_tolerance=0.01,...)

Explicitly requested approximation from the actual negative log posterior, not a likelihood-only/Gauss–Newton substitute. Checks optimizer convergence, stationarity, gradients, independent step-halved verification of the AD Hessian, positive curvature and condition number. Explicit finite differences use a step-halved finite-difference Hessian. Invalid or weak curvature is reported through LaplaceFailure. A local check cannot establish Gaussian shape, unimodality or accurate tail coverage.

source
PopulationBalanceModels.likelihood_gradient — Method

Log-likelihood gradient in inference coordinates. Automatic mode uses a configured SciML sensitivity adapter or ForwardDiff; finite differences require an explicit request.

source
PopulationBalanceModels.marginal_covariance — Method

Select the kinetic (or nuisance) marginal block from the FULL Laplace covariance, in inference coordinates. This never inverts a conditional Hessian subblock.

source
PopulationBalanceModels.parameter_draws — Method

Select retained MCMC draws. indices records their columns in reshape(samples.z, length(problem.parameters), :); preserve it with exported predictions because seeded permutations can differ across Julia releases.

source
PopulationBalanceModels.parameter_draws — Method

Draw from an explicitly labelled Laplace or Gauss–Newton approximation and transform every draw to physical coordinates. This performs no forward PBM solves; support violations are flagged, not filtered.

source
PopulationBalanceModels.posterior_gradient — Method

Log-posterior gradient in declared inference coordinates. The default uses ForwardDiff or configured SciML sensitivities; a supplied callback is honored in automatic mode. Finite differences are explicit and are also used for independent verification.

source
PopulationBalanceModels.posterior_predictive — Method
posterior_predictive(problem,draws;max_solves,measurement_noise=false,seed=2022)

Propagate an explicit finite set of parameter draws. Budget counts one forward solve per experiment per draw and is checked BEFORE execution. Returns raw predictions, latent measurement means and optionally fresh measurement noise. Multinomial predictions condition on the observed snapshot totals. Contrast Gaussian outputs remain in contrast coordinates; they are not fabricated PSDs. Failures are returned by draw with their messages and counted; no clipping occurs.

source
PopulationBalanceModels.prior_sensitivity — Method

Fit explicitly supplied alternative-prior problems; compare z modes, Laplace standard deviations, and shifts in reference posterior SD units. This reports prior dependence without treating it as data identifiability.

source
PopulationBalanceModels.refinement_study — Method

Refit named numerical variants, comparing mode changes to reference Laplace SDs and predictions at a common parameter vector. Label spatial, domain, integration and closure variants separately; closure comparisons measure model approximation too.

source
PopulationBalanceModels.replace_priors — Method

Replace all scalar prior declarations, retaining transforms, data, histories and parameter sharing. Supply one explicitly coordinated Prior per fitted parameter.

source
PopulationBalanceModels.CalibrationProblem — Type
CalibrationProblem(experiments; parameters=(z,experiment)->z, dt=nothing, solver=nothing)

parameters maps unconstrained optimization coordinates into physical model parameters separately for each experiment, e.g. positive rate = exp(z[1]). Initial conditions/fields differ by experiment. The same parameter vector can therefore be fitted jointly to several experiments and measurement types. Supply dt for SSPRK33, or solver=(problem,times)->solution for an external integrator. A solver must return precisely those output times and must check its own success code. Initial data that depend on fitted parameters require a separate model construction; the parameter map changes p, not u0.

source
PopulationBalanceModels.objective — Method

Known-covariance Gaussian negative log likelihood, including normalization, for Observation blocks. For ResidualObservation blocks, returns the sum of their weighted group-mean squared discrepancies, without likelihood normalization. The two interpretations cannot be mixed. NumericalFailure alone can optionally be mapped to Inf. Programming/model-definition errors are never silently turned into optimizer penalties.

source
PopulationBalanceModels.predictions — Method

Predicted output matrices, grouped by experiment and observation. Uses the calibration's solver and parameter map.

source
PopulationBalanceModels.sensitivity_report — Method

Residual Jacobian (ForwardDiff by default) in optimization coordinates, its singular values and numerical rank. Local covariance is (J'J)^(-1) ONLY at full column rank. This local covariance alone specifies neither a confidence level nor structural identifiability. Use confidenceellipsoid with its assumptions and checks, and profilelikelihood to investigate local asymmetry. Select derivatives=:finite_difference explicitly for an incompatible forward model.

source
PopulationBalanceModels.DifferentiationFailure — Type

An AD incompatibility, retaining the original exception. Select derivatives=:finite_difference explicitly for a backend that cannot propagate dual numbers; no silent fallback is made.

source
PopulationBalanceModels.SciMLSensitivitySolver — Type
SciMLSensitivitySolver(algorithm; sensitivity=:auto, reltol=1e-7, abstol=1e-9, kwargs...)

Optional inference solver enabled by SciMLBase, SciMLSensitivity and ReverseDiff (loaded by SciMLSensitivity). Automatic selection uses continuous forward sensitivities for at most 16 coordinates and an interpolating adjoint otherwise. Explicit :forward/:adjoint choices are available. Includes parameter-dependent initial states and direct likelihood, response and noise dependence. ODE parameters are the full inference vector. Supports differentiable fixed-representation residuals; changing grid topology, direct shifts, eigen-based QMOM inversion and user callbacks may be ineligible. Hessians use nested ForwardDiff through the primal solve, not an unverified second derivative of an adjoint. Finite differences are an explicit alternative.

source
PopulationBalanceModels.GaussNewtonApproximation — Type

Local Gaussian in the declared inference coordinates, with precision jacobian' * jacobian + prior_hessian. The Jacobian is of the joint whitened Gaussian residuals. This omits residual-weighted second prediction derivatives; it is distinct from full-Hessian LaplaceApproximation and sampler tuning.

source
PopulationBalanceModels.GaussNewtonFailure — Type

A rejected sensitivity-based approximation. report retains the failed checks; no ridge, pseudoinverse or replacement uncertainty is inserted.

source
PopulationBalanceModels.gauss_newton_approximation — Method
gauss_newton_approximation(problem, map; step=cbrt(eps(Float64)), ...)

Construct sensitivity-based posterior covariance at a converged MAP point: P = J'J + ∇²[-logprior(problem,z)], C = P⁻¹. J differentiates the joint whitened residuals after observation responses and any independent contrasts. Every experiment, time and fitted parameter (including nuisance parameters) is included. Prior curvature uses the declared inference density, including physical-prior transformation Jacobians exactly once.

Initially supports fixed scalar/array Gaussian standard deviations or covariance matrices. Parameter-dependent noise callbacks, count likelihoods and truncated Gaussian likelihoods are rejected, rather than omitting their information. ForwardDiff is the default Jacobian backend; derivatives=:finite_difference is explicit. An external ODE adapter must support that prediction-Jacobian path; this function does not silently select an adjoint or a different solver.

Checks MAP stationarity, residual/target gradient consistency, independent step-halved prediction sensitivities and prior curvature, positive joint precision and conditioning. information_tolerance bounds the precision perturbation in its own covariance metric, including weak directions. No jitter or pseudoinverse is used. Data rank deficiency is reported and may be supported by prior curvature; it is not interpreted as identification by the data.

The approximation omits residual-weighted second prediction derivatives. Successful checks establish neither a full-posterior minimum nor Gaussian tails, unimodality or model adequacy. It is not full-Hessian Laplace. Draws transform to physical parameters and report prior/constraint support violations without truncation. No PBM solves are needed to draw parameters; predictive propagation still costs solves. All covariance entries are in inference units.

Identity coordinates with optional location and positive scale: θ=location+scale*z.

PopulationBalanceModels.LogTransform — Type

Positive physical parameter θ=scale*exp(z); scale is a fixed physical reference.

PopulationBalanceModels.LogitTransform — Type

PopulationBalanceModels.ParameterSpec — Type
ParameterSpec(name; initial, prior, transform=IdentityTransform(), role=:kinetic, experiment=nothing)

One fitted scalar. initial is physical; optimization and sampling use z. experiment=nothing shares it across experiments; an experiment name makes it local. Use role=:nuisance for initial conditions, gains, or noise parameters. Fixed parameters belong in the estimation problem or experiment's fixed tuple.

Prior(distribution; coordinates)

Declare a univariate density in :physical or :inference coordinates. Physical densities receive the transform Jacobian exactly once. Inference densities receive none. There is intentionally no implicit coordinate choice.

Initial inference-coordinate vector, obtained from physical ParameterSpec initial values.

physical_parameters(problem,z[,experiment_name])

Return (shared=...,experiments=...), including fixed values. With an experiment name return its merged physical parameter tuple. Shared names cannot be shadowed locally. The returned mode is the transform of a z-density mode; it is generally not the physical-density mode.

PopulationBalanceModels.check_sampling_map — Method
check_sampling_map(problem, map, z; derivatives=problem.derivatives,
                   step=cbrt(eps(Float64)), tolerance=1e-3)

Check a supplied sampling map at an inference-coordinate point z. The named fields are to_sampler, from_sampler, logabsdetjac and label. logabsdetjac(y) means log|det D(fromsampler)(y)|. The sampler density is `logposterior(problem,fromsampler(y)) + logabsdetjac(y)`.

Checks both inverse directions, the Jacobian determinant, and the pulled-back posterior gradient against independent step-halved differences. Repeat at representative points and tails in the ORIGINAL posterior support. Callbacks must be pure and define a bijection covering that entire support; finite tests cannot certify global coverage or injectivity. The sampler also checks inverse and determinant consistency at every mapped target evaluation. No priors or physical parameter transforms are redefined by this auxiliary change.

source
PopulationBalanceModels.InferenceExperiment — Method
InferenceExperiment(name, problem::StationaryPBMProblem, measurements...;
                    solver=StationarySolver(), setup, fixed=NamedTuple())

One stationary operating point, sharing the transient framework's parameters, priors, likelihoods, responses and source tags. Declare timeless measurements with Measurement(data, observable; likelihood=...). Matrix columns are replicates of the same state. Distinct operating points need distinct experiments. setup(theta, base) must return a stationary problem. A custom one-argument solver must return a converged, checked StationaryPBMSolution for that problem. No timestep or artificial time series is used.

source
PopulationBalanceModels.StationarySolver — Type
StationarySolver([algorithm]; condition_limit=1e12, abstol=1e-11, kwargs...)

Checked stationary forward solver for calibration and Bayesian estimation. Requires the optional NonlinearSolve integration. Remaining keywords pass to solve_stationary. Each evaluation starts from the problem's declared guess; there is no hidden continuation or warm-start history.

ForwardDiff predictions differentiate the equilibrium equations implicitly, not the nonlinear iterations. The equilibrated state Jacobian must be nonsingular with condition number below condition_limit. This local result requires a smooth, isolated root on a consistent branch. Quadrature closures that cannot differentiate their residual must explicitly use derivatives=:finite_difference in the estimation/calibration problem. The current implicit implementation uses dense Jacobians and factorizations.

source
PopulationBalanceModels.observe — Method
observe(observable, solution::PBMSolution; index=length(solution.u))
observe(observable, solution::StationaryPBMSolution)
observe(observable, problem, state; time) # time required for transient states

Evaluate one state using the existing representation-aware observation rules. Returns a vector, including for scalar observables. Stationary solutions must have passed convergence checks; their declared autonomous/frozen evaluation time is used. CellObservable selects a local axial state. Histograms/CDFs from moment states still require an explicit reconstruction; DQMOM entries are not interpreted as raw moments or PSD bins.

source
PopulationBalanceModels.DistributionObservable — Type
DistributionObservable(edges; coordinate, population=nothing, weight=x->1, normalize=false, response=nothing)

Integrate a sectional density over measurement bins, independently of solver bins. weight specifies number, volume or instrument intensity weighting. Optional response(lo,hi,x,p,t) is the probability that true size x is detected in that measured bin (including sizing error/thresholds). Weighted integrals use eight-point Gauss quadrature within solver bins. Physical discontinuities should coincide with integration edges or use a custom observation model. A moment state needs an explicitly supplied reconstruction via Function/SystemObservable.

source
PopulationBalanceModels.EstimationProblem — Type
EstimationProblem(parameters,experiments;fixed=NamedTuple(),constraints=p->true,gradient=nothing)

Shared statistical model for MAP, Laplace and sampling. Priors are independent scalar declarations; use inference transforms for bounds and constraints for additional physical restrictions. gradient(z) may supply a log-posterior gradient; it is checked against finite differences before fitting/sampling. derivatives=:auto uses ForwardDiff or a SciMLSensitivitySolver adapter. Finite differences require derivatives=:finite_difference. Differentiability depends on the solver, representation and callbacks; failures never silently switch methods. All fitted nuisance parameters are included.

source
PopulationBalanceModels.GaussianLikelihood — Type
GaussianLikelihood(;sigma=nothing,covariance=nothing,contrasts=nothing)

Normalized Gaussian likelihood, including its determinant. Supply a positive standard deviation or covariance (constant or (theta,experiment)->value). Covariance acts on vec(data). For normalized fractions supply a full-row-rank contrast matrix annihilating the all-ones vector; a singular full covariance is projected before factorization. No fictitious particle count is introduced.

source
PopulationBalanceModels.InferenceExperiment — Type
InferenceExperiment(name,problem,measurements...;dt=nothing,solver=nothing,setup,fixed=NamedTuple())

One operating history. setup(theta,base_problem) rebuilds parameters and, optionally, uncertain initial conditions/bulk states. The default merges theta into a NamedTuple p. A custom solver must check success and return exactly the requested times. Existing Observation blocks can be adapted with Measurement.

PopulationBalanceModels.MAPResult — Type

MAP output, including physical parameters, declared coordinate specifications, component densities, diagnostics and optional Gauss–Newton or Laplace uncertainty.

PopulationBalanceModels.Measurement — Type
Measurement(times,data,observable; likelihood,response=(y,theta,experiment)->y,source=nothing)

Rows are outputs, columns are times. response can apply an inferred calibration factor. Mark blocks derived from the same measurements with the same source; an experiment rejects duplicate source tags. Combine correlated derived outputs in one joint block instead of treating histogram and derived moments independently.

PopulationBalanceModels.Measurement — Method

Measurement(data, observable; likelihood, response, source) declares stationary measurements without timestamps. Vectors contain outputs; matrix columns are replicate observations of one equilibrium. Likelihood normalization, covariance, response and source-dependence rules are unchanged.

PopulationBalanceModels.MultinomialLikelihood — Type

Bin counts conditional on each column's observed sampled-particle total. Predictions are nonnegative bin integrals, normalized over the declared measurement window.

source
PopulationBalanceModels.PoissonLikelihood — Type

Absolute bin counts with a known sampling exposure/volume. Exposure may be a scalar or a matrix matching data; it is never inferred from histogram normalization.

source
PopulationBalanceModels.TruncatedGaussianLikelihood — Type
TruncatedGaussianLikelihood(;sigma,lower=0.0)

Independent Gaussian measurements conditioned to be at least lower. The normalization depends on the predicted density and sigma and is retained in MAP, Laplace, profiles and sampling. Sigma may be scalar, data-shaped, or a (theta,experiment)->value callback. Correlated truncation is not implemented. The latent PBM density is the underlying Gaussian location, not the conditional mean. This model neither clips measurements nor assigns particle counts.

Load Optim for nuisance-reoptimized estimation_profile(...;target=:likelihood|:posterior); posterior profiles have no ordinary likelihood confidence cutoff.

PopulationBalanceModels.logposterior — Method

The single posterior density in declared z coordinates used by MAP, Laplace and MCMC. NumericalFailure can be rejected explicitly; programming errors propagate.

source
PopulationBalanceModels.logprior — Method

Sum declared prior densities in inference coordinates, adding each physical prior's Jacobian exactly once. No PBM solve is performed.

source
PopulationBalanceModels.posterior_components — Method

Separate log-likelihood, transformed log-prior and their sum at the same coordinate vector.

source
PopulationBalanceModels.sample_posterior — Function

Load AdvancedHMC and MCMCDiagnosticTools to enable explicit sample_posterior(problem;...). Sampling is never automatic in fit. initial_covariance=C optionally initializes the HMC inverse mass matrix in sampling coordinates (inference coordinates by default); C must be finite, symmetric positive definite and is used only for tuning, not returned as a posterior uncertainty estimate. It cannot be combined with laplace initialization. An optional sampling_map=(to_sampler,from_sampler,logabsdetjac,label) changes only auxiliary sampler coordinates; logabsdetjac is the log absolute determinant of the Jacobian of fromsampler. Inverses and Jacobians are checked at every mapped target evaluation; transformed gradients are independently checked at chain starts. Use checksamplingmap at additional representative inference-coordinate points, including tails. Returned z values and statistics.logdensity stay in declared inference coordinates.

source
StatsAPI.loglikelihood — Method

Sum normalized measurement log likelihoods across every time, block and experiment. Priors are excluded; no bin/snapshot averaging is applied.

source
PopulationBalanceModels.ConfidenceEllipsoid — Type

A local joint confidence ellipsoid in optimization coordinates; construct with confidence_ellipsoid.

source
PopulationBalanceModels.confidence_ellipsoid — Method
confidence_ellipsoid(calibration, estimate; level=0.95, variance=:known, ...)

Local Gauss–Newton joint region (z-ẑ)' inv(C) (z-ẑ) <= cutoff. Known absolute errors use chi-square(p); relative weights with an estimated common variance use p*F(p,n-p). Rejects rank deficiency, a nonstationary fit, unverified derivatives, and a nonconverged FitResult. If a refined calibration is supplied, also checks forward and derivative convergence. A nonlinear parameter transform maps the region to a generally nonellipsoidal physical region. The approximation is not a global coverage guarantee.

source
PopulationBalanceModels.ellipse_points — Method
ellipse_points(region; pair=(1,2), n=181)

2×n boundary points of the region's projection onto a coordinate pair. The cutoff remains that of the full joint region; this is not a newly calculated pairwise confidence level. Apply physical transforms explicitly to the points.

source
PopulationBalanceModels.fit_diagnostics — Method
fit_diagnostics(calibration, estimate; variance=:known, refined=nothing, ...)

Assess a fit in its optimization coordinates. Returns whitened residuals, Gauss–Newton covariance/correlation, rank, residual degrees of freedom, stationarity, and agreement with an independent central-difference check. variance=:known uses the supplied absolute observation errors; :estimated treats them as relative weights with one unknown common variance, estimated as RSS/(n-rank).

For a stationary full-rank fit with known errors, the chi-square goodness-of-fit p-value uses n-p degrees of freedom (a local nonlinear approximation). refined may supply a finer forward calculation for the same measurements; the report measures its changes in whitened predictions and derivatives. These diagnostics do not establish model validity or global identifiability.

source
PopulationBalanceModels.fit_multistart — Method

Fit from explicit starting vectors and select the lowest-objective converged result. Requires an installed fitting backend; reports failed starts.

source
PopulationBalanceModels.profile_likelihood — Function

Load Optim to evaluate profile_likelihood(calibration, fitted, parameter_index, values; ...), reoptimizing nuisance parameters at each fixed value.
