Forward uncertainty quantification

These constructors and operations propagate a declared input law through eligible forward problems without observations or fitting. Existing posterior draws are one possible input source. MC and non-intrusive PCE use the same scenario and observation definitions, with explicit solve budgets. PCE supports SVD regression and probability-quadrature projection, an extensible orthonormal-basis contract, and validation/refinement before selecting a surrogate.

The UQ guide provides a complete first run, input-coordinate conventions, failure handling and the distinction between input uncertainty, sampling error and surrogate error. The milling case illustrates a larger workflow.

PopulationBalanceModels.PCEBasis — Type
PCEBasis(family, diagonal, offdiagonal; shift=0, scale=1)

Probability-orthonormal univariate basis, with φ₀ = 1 and recurrence z*φₖ = bₖ₊₁*φₖ₊₁ + aₖ*φₖ + bₖ*φₖ₋₁, where z = (x-shift)/scale, diagonal[k+1] = aₖ and offdiagonal[k] = bₖ. There must be one more diagonal than offdiagonal entry; the latter are positive.

Extension implementations of pce_basis return this description. The coefficients must be orthonormal under the probability law of the declared distribution, not an unnormalized weight. This is an extension contract; the constructor checks finite coefficients, not the asserted probability law.

PopulationBalanceModels.pce_basis — Method
pce_basis(distribution, degree)

Return a PCEBasis through degree. Built-in probability-orthonormal families are Normal/Hermite, Uniform/Legendre and Beta/Jacobi. For Beta(α,β), z=2x-1 has Jacobi weight (1-z)^(β-1)*(1+z)^(α-1). An affine physical interval can instead be specified by UncertainInputs.map.

Extend this function for another Distributions.UnivariateDistribution by returning a recurrence of the requested degree. Regression and Gaussian quadrature use this same hook. Distributions must also support ordinary sampling, insupport, and quantile when using an LHS design. Arbitrary joint/posterior laws require an explicit reference transformation; no joint basis is inferred.

source
PopulationBalanceModels.pce_quadrature — Method
pce_quadrature(inputs; order, max_points=100_000)

Tensor-product Gaussian nodes and probability weights for the declared independent reference marginals. order is a positive node count per coordinate, or a tuple of counts. An order-q rule integrates univariate polynomials through degree 2q-1. Golub–Welsch nodes and Christoffel weights use the same orthonormal recurrence as regression, retaining small Gaussian tail weights. The product size is checked against max_points before allocation.

The returned recorded design has samples, weights, names and coordinates; use PolynomialChaos(p; construction=:projection) with fit_pce. It changes neither the input law nor the physical input map. Increase quadrature order separately from polynomial degree and validate nonpolynomial outputs. This is full tensor quadrature, not a sparse-grid or adaptive construction.

PopulationBalanceModels.MonteCarlo — Type

MonteCarlo(n; seed=2022) requests n serial joint realizations. The solve budget is supplied separately to propagate; supplied sample sets are used in their recorded order rather than resampled.

source
PopulationBalanceModels.UncertainInputs — Type
UncertainInputs(source; map=identity, valid=x->true, names=nothing,
                coordinates=:physical, iid=nothing, metadata=(;), ids=nothing)

Forward uncertainty without observations or a likelihood. source is a named tuple of independent univariate distributions, a univariate/joint distribution, a sampler rng -> joint_sample, or supplied samples (matrix columns or vector entries). map deterministically maps a whole joint sample to physical inputs; valid declares physical admissibility. Samples are never clipped or redrawn.

Distributions are iid sources. Supplied samples and custom samplers default to iid=false; declaring iid=true is the caller's sampling assumption. Correlation inside a joint distribution/sample is preserved. coordinates names the input coordinates before map; record the transformation in metadata.

UncertainInputs(parameter_draws(...)) preserves physical draws, inference coordinates, identities and support flags. MCMC draws are not declared iid. UncertainInputs(estimation, posterior; n, seed) selects through parameter_draws.

PopulationBalanceModels.PCEFailure — Type

A failed training/validation ensemble, retained as evaluations for diagnosis. Failed points are never removed to manufacture a regression fit.

source
PopulationBalanceModels.PCESurrogate — Type

Fitted non-intrusive PCE. Coefficient rows follow multi_indices; columns follow the training output/time layout. training and validation retain their distinct full-model evaluations. Inspect diagnostics before using the surrogate.

source
PopulationBalanceModels.PolynomialChaos — Type
PolynomialChaos(degree; construction=:regression, condition_limit=1e8,
                quadrature_tolerance=1e-10)

Full total-degree non-intrusive PCE. :regression uses SVD least squares; :projection uses recorded probability quadrature weights and checks discrete basis orthonormality to quadrature_tolerance. That check does not establish quadrature accuracy for a nonpolynomial output: refine and validate separately.

Independent Normal, Uniform and Beta reference marginals use probability- orthonormal Hermite, Legendre and Jacobi bases; pce_basis is the extension hook. A declared map may produce correlated physical inputs. No basis is inferred from posterior samples. Both constructions reuse ordinary forward solves.

source
PopulationBalanceModels.evaluate_pce — Method

Evaluate a fitted PCE at supplied reference points, or seeded MonteCarlo reference draws, with zero full-model solves. Negative surrogate outputs are retained. Returned UQResult can supply pointwise surrogate quantiles via uq_summary; these include surrogate approximation error only when separately assessed.

source
PopulationBalanceModels.fit_pce — Method
fit_pce(problem, PolynomialChaos(degree); design, validation=nothing,
        max_solves, validation_atol=0, validation_rtol=0.05)

Fit all outputs/times using SVD regression or probability-weighted projection. Rank/condition and quadrature checks precede solves. Designs and validation can be recorded designs, matrices or existing UQResults from this same UQProblem. Reusing full-model evaluations incurs zero new solves; surrogate outputs cannot be used as training or validation references. No ridge or missing-point deletion is used. Validation must not overlap training; disjointness alone does not prove independence. Weighted quadrature nodes are not an MC validation sample.

Validation reports passed using validate_pce's per-output/time RMSE criteria. A rejected or untested surrogate remains available for diagnosis; diagnostics(pce).accuracy_status distinguishes it from a passing fit. Use refine_pce to select only after validation and refinement checks.

source
PopulationBalanceModels.pce_design — Method
pce_design(inputs; n, method=:lhs, seed=2022, bounds=nothing)

Record an n-point training design in the input source's reference coordinates. Default LHS stratifies each marginal CDF on its entire support. Optional d-by-2 bounds instead defines a uniformly stratified training box; this changes the training design, never the propagated input law. Save the returned points, not only their seed. method=:mc supplies ordinary random training points.

source
PopulationBalanceModels.uq_summary — Method

Analytical mean/variance/covariance of an orthonormal PCE under its declared reference law. Quantiles require evaluatepce followed by uqsummary, not a Gaussian assumption. These moments do not include regression/validation error.

source
PopulationBalanceModels.validate_pce — Method
validate_pce(pce, reference; atol=0, rtol=0.05)

Compare with disjoint full-model evaluations. Every output/time must satisfy RMSE <= atol + rtol*reference_SD to set passed=true. atol has output units; rtol is relative to validation-output population SD (denominator n). Scalars apply everywhere; a NamedTuple can supply a scalar or output-by-time matrix per named block. Constant outputs require a suitable absolute tolerance.

Signed bias, maximum error and normalized RMSE remain available even on failure. Validation does not establish tail/event accuracy or PBM numerical convergence. Inputs used for choosing a surrogate are a selection set; a fresh independent test set is needed for an assessment unaffected by that choice. No failed runs are dropped and no relative error is assigned at zero reference variance.

PopulationBalanceModels.UQProblem — Type
UQProblem(base, inputs; outputs, times=nothing, setup, solver=nothing,
          dt=nothing, method=SSPRK33(), output_coordinates=(;),
          negative_tolerance=1e-12)

One forward scenario with named observable outputs, without estimation data. setup(physical_inputs, base) returns a PBMProblem or StationaryPBMProblem and may rebuild initial states, fields, meshes and compiled operators. The default merges physical NamedTuple inputs into base.p. Setup must not mutate base.

Transient outputs share explicit increasing times. Supply dt for native integration or solver(problem,times) returning a checked PBMSolution. Stationary outputs have no times and use solver(problem) (StationarySolver by default). External solvers must check their own successful completion; native guarantees do not transfer. Saved states also receive the stated nonnegativity check.

outputs is a NamedTuple of existing observables, including FunctionObservable and SystemObservable callbacks. output_coordinates records each output's units, weighting and coordinates; callback declarations are not a proof of their units. Representation-aware observations retain their ordinary restrictions.

source
PopulationBalanceModels.UQResult — Type

Raw forward ensemble. values[:,i] belongs to ids[i]; failed samples remain as NaNs with an explicit stage/message. Layout records named blocks, output/time order and coordinates. metadata.solves counts actual solver invocations.

PopulationBalanceModels.diagnostics — Method

Counts, timing, coordinate and sampling assumptions; numerical failures remain indexed in the result. This report is separate from input/output uncertainty.

source
PopulationBalanceModels.propagate — Method
propagate(problem, MonteCarlo(n; seed); max_solves, samples=nothing)

Run deterministic serial forward propagation, one solve supplies all outputs and times. The worst-case solve budget is checked before execution. Optional samples is a d-by-n matrix or a recorded pce_design; these are design evaluations, not iid MC draws. Only NumericalFailure is recorded; programming errors propagate. Invalid inputs are recorded without replacement. Summary statistics reject failed ensembles unless success conditioning is explicitly requested.

source
PopulationBalanceModels.uq_summary — Method
uq_summary(ensemble; probabilities=(.025,.5,.975), events=(;),
           covariance=true, conditional_on_success=false)

Named means, unbiased variances, pointwise empirical quantiles and optional full output/time covariance in the recorded flattening order. Event callbacks receive one NamedTuple of output-by-time blocks and return a Bool per realization. Only declared iid samples receive mean MCSEs and binomial event intervals. No iid error estimate is assigned to imported MCMC samples. Output SD is not the sampling error of a mean, nor is a pointwise band simultaneous coverage. Sampling errors for variance and quantiles are not estimated by this routine.

source
PopulationBalanceModels.PCERefinement — Type

Result of refine_pce. candidates and history retain every completed attempt. surrogate is present only when converged=true: two successive, distinct candidates passed validation and their analytical means/variances met the requested stability criteria. Otherwise it is nothing; diagnostic fits remain in candidates. This is an empirical selection rule, not a proof of spectral convergence or an error bound over the entire input support.

PopulationBalanceModels.refine_pce — Method
refine_pce(problem, methods; designs, validation, max_solves,
           validation_atol=0, validation_rtol=0.05,
           mean_atol=0, mean_rtol=0.01,
           variance_atol=0, variance_rtol=0.05)

Evaluate an explicitly ordered plan of at least two PolynomialChaos methods and matching training designs. Increase degree, regression sample size or quadrature order in designs; the plan, seeds and all evaluated points remain available. A single disjoint full-model validation set is reused across the plan.

Stop only after two consecutive candidates pass validation and their analytical PCE means/variances agree within the respective atol + rtol*scale limits. Here scale is the larger absolute mean or variance of the pair; absolute limits have output or squared-output units. Scalars or named output-by-time tolerances work as in validate_pce. Set absolute limits for near-zero means/variances. Exhausting the plan returns converged=false, surrogate=nothing. All candidates and detailed validation/stability results are retained. A forward failure stops with stop_reason=:forward_failure; diagnostics(study).failure is a PCEFailure retaining its sample-level evaluations.

max_solves must cover the entire plan and validation before any solve starts. Existing UQResult designs/validation cost zero new solves. Other designs each incur their full stated count, including repeated points across designs; reuse evaluations explicitly to avoid those repeats. One solve still supplies every output and time. Programming errors propagate. No failed sample or candidate is silently skipped, and a failed refinement never returns a selected surrogate.

Validation used for this selection is not an untouched final test. Use fresh inputs with validate_pce(study.surrogate, test) for a final assessment. Tail/ event accuracy, input-law validity, and forward spatial/time/closure refinement remain separate checks. The full tensor projection backend is not adaptive PCE.
