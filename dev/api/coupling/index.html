Coupling and accounting

PBMSystem combines named populations and shared bulk balances. Prefer named population, bulk and cumulative accessors to packed-state offsets. Instantaneous accounting rates, historical loss ledgers and physical reservoirs have distinct meanings.

See Coupled systems for callback, exchange and tensor contracts, and Axially dispersed reactors for physical transport. Axial domain declarations and compiled adapters also appear under Models and Compilation.

PopulationBalanceModels.accounting_rates — Function

Instantaneous rates for the cumulative states, evaluated from the same residual. Characteristic moment boundary rates are discrete events and are reported through cumulative increments of MeasureEuler, rather than an invented density trace.

source
PopulationBalanceModels.cumulative — Function
cumulative(problem_or_operator, state, population, mechanism, property=:number)

Historical unresolved number or declared property, by named population and removal mechanism. state may be a physical state or a derivative (instantaneous rate). Use accounting_rates(problem,state,p,t) for a named tree of rate values. For axial systems return one history per reactor cell; these histories do not flow.

source
PopulationBalanceModels.CumulativeAccounting — Type
CumulativeAccounting(population; properties=(material=3,))

Append historical removal states to a PBMSystem. Each mechanism has a particle number ledger and the declared raw-power properties (e.g. L³ per process volume). Multiply material by the same density/shape factor as the bulk exchange to obtain material concentration. Ledgers have no subsequent kinetics and are not advected. Collision conservation requires the property to be proportional to the collision's additive coordinate. Defaults without accounting retain their original behavior.

source
PopulationBalanceModels.MomentExchange — Type

Balance a bulk scalar against factor*dμ[order] from selected moment mechanisms. The invariant c+factor*μ[order] assumes a factor fixed in time and state; varying conversion factors require their additional derivative balance.

source
PopulationBalanceModels.ConservativeExchange — Type

Balance a named bulk concentration against the discrete resolved measure change from selected population mechanisms. weight(size,p,t,localcontext) is mass (or another exchanged quantity) per particle. This ensures discrete conservation; it is not an independently discretized continuum moment closure. The default mechanisms are `(:growth,:sizediffusion,:birth,:nucleation)`; diffusion changes nonlinear material moments even when it preserves number. Explicit selections are retained. Do not also subtract these rates in bulk_rhs.

PopulationBalanceModels.PBMSystem — Type
PBMSystem(populations; bulk_rhs=(ctx,p,t)->(;), interactions=(),
          exchanges=(), fields=(p,t)->(;), nonnegative_bulk=())

A NamedTuple of separately compiled populations, shared scalar bulk states, and simultaneous interactions. Populations may use different Grid1D, Grid2D or supported moment representations. Tensor population/derivative accessors return matrices in the declared Grid2D shape; the system solver state stays flat. Bulk initial values are supplied to PBMProblem through bulk0.

PopulationBalanceModels.suggest_dt — Method
suggest_dt(operator::CompiledSystem, u, p, t; cfl=0.5)

Minimum local sectional recommendation, with each population's growth, SizeDiffusion and loss rates summed using the current shared bulk state. Requires Grid1D/Grid2D sectional populations without inter-population interactions. It does not bound bulk depletion or future coefficient changes; native stage checks still apply. Moment populations and custom interaction bounds are unsupported.
