Observations and discrepancies

Observation operators map eligible forward solutions to measurements. Explicit conditioning windows, weighting and reconstruction assumptions remain part of that map. The same operators serve transient and stationary calculations.

Conditional CDFs and quantiles integrate partial cells of bin populations and reject an empty window. Deterministic residual/Wasserstein comparison blocks have different statistical meanings from a measurement likelihood. See Parameter estimation for both workflows, and Likelihoods and Bayesian estimation for Measurement and DistributionObservable.

PopulationBalanceModels.ResidualObservation — Type
ResidualObservation(times, data, observable; scale=1, weight=1, name=:residual)

A deterministic discrepancy block, contributing weight * mean(((prediction- data)/scale).^2) to objective. The scale is a comparison unit, not a sensor standard deviation. Cannot be mixed with Gaussian Observation blocks. Sensitivity singular values remain meaningful; confidence intervals do not follow from these weights.

source
PopulationBalanceModels.WassersteinObservation — Method
WassersteinObservation(time, x, F, population; window, points=256, scale=1, weight=1)

One conditional-number distribution discrepancy, weight * W₂²/scale². Midpoint quadrature integrates squared quantile differences on (0,1). x,F describe a conditional number CDF over the declared window. Quadrature points are integration nodes, not independent experimental observations.

source
PopulationBalanceModels.WassersteinObservation — Method

WassersteinObservation(x, F, population; window, ...) declares the same conditional-number discrepancy for a stationary operating point, without time.

source
PopulationBalanceModels.cdf_quantiles — Method

Generalized inverse of a tabulated, piecewise-linear CDF. No density smoothing.

source
PopulationBalanceModels.conditional_cdf — Method
conditional_cdf(grid, N, points; window=(first(grid.edges), last(grid.edges)))

Conditional number CDF of a one-coordinate sectional population. N contains bin integrals. Integrates the piecewise-constant density, including partial window cells. Empty windows and negative populations are invalid observations. No moment reconstruction or smoothing is implicit.

source
PopulationBalanceModels.conditional_quantiles — Method
conditional_quantiles(grid, N, probabilities; window=...)

Generalized inverse of conditional_cdf, with exact partial-cell integration. Probabilities must increase. Flat CDF intervals carry no probability mass.

source
PopulationBalanceModels.loss_contributions — Method

Individual deterministic discrepancy contributions, with no likelihood interpretation.

PopulationBalanceModels.CellObservable — Type

CellObservable(observable, cell) evaluates a local observation in one axial cell, using that cell's intrinsic representation and population/bulk layout. The result is a local concentration, not a reactor-integrated inventory.

PopulationBalanceModels.Observation — Type
Observation(times, data, observable; sigma=1.0, covariance=nothing)

Rows are measured outputs; columns are times. Known independent Gaussian standard deviations can be a scalar or a matrix matching data. For a scalar observable, a vector of data is accepted. Missing data must be explicitly selected before construction. Alternatively supply a fixed positive-definite covariance for vec(data) (outputs within each time, then times). It can include correlations across outputs and times within this observation. Do not supply sigma as well. Different Observation objects are independent blocks. Normalized histograms have a singular covariance and need independent contrasts or a likelihood for compositional data.

source
PopulationBalanceModels.Observation — Method

Observation(data, observable; sigma, covariance) declares stationary data. A vector contains outputs at one operating point; matrix columns are replicate measurements of that same state. No artificial observation time is introduced.
