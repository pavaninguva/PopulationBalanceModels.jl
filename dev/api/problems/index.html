Problems, solvers and integrations

Transient problems provide initial conditions and a time span; stationary problems provide a numerical guess. Native integration, optional external ODE solvers and stationary root solvers retain their own compatibility and state checks. suggest_dt recommends a local explicit step; it is not an adaptive controller.

See Time integration, Stationary population balances and the optional-dependency setup. The shared optional fit entry point is used by the parameter-estimation interfaces.

PopulationBalanceModels.continue_stationary — Method
continue_stationary(problem, parameters, (λ0,λ1); algorithm=nothing,
                    initial_step=(λ1-λ0)/10, min_step=(λ1-λ0)*1e-6,
                    max_step=(λ1-λ0)/4, maxsteps=1000, solve_kwargs...)

Natural-parameter continuation. parameters(λ) returns the complete physical parameter object for that solve. Solve the anchor, then warm-start from each accepted state. Failed corrections halve the increment; successful corrections increase it by 1.5 up to maxstep. Each correction uses solvestationary and therefore the identical assembled physics, constraints and balance checks.

This is parameter continuation, not time integration or pseudo-arclength: requires increasing finite λspan and cannot follow a fold that reverses λ. No physical admissibility or root-existence guarantee is implied. Every callback must be pure, including parameters(λ). The last accepted state is preserved on failure. Mesh continuation instead requires recompilation and conservative state transfer, and is not performed by this helper.

PopulationBalanceModels.StationaryPBMProblem — Type
StationaryPBMProblem(operator, guess; p=(;), autonomous=false, time=nothing,
                     residual_scale=1, constraints=(), negative_tolerance=1e-12)
StationaryPBMProblem(system::PBMSystem, populations::NamedTuple; bulk=(;), kwargs...)

Stationary physical balances, with no time derivative or time span. guess is a numerical initial guess, not an initial condition. States retain their usual meaning: sectional entries are bin integrals; moment entries follow the selected representation. Use autonomous=true to declare time-independent callbacks and fields, or time=t to explicitly freeze prescribed conditions at t. The latter is an instantaneous stationary problem, not a solution for a changing history.

Positive residual_scale (scalar or state-shaped array) divides physical rates before root finding. Optional constraints=(row => f, ...) replace redundant balance rows by dimensionless equations f(u,p,t)=0, e.g. a conserved inventory. They do not append equations. All original physical balances are checked again at the root. User bulk accumulators must be removed from the stationary model; native historical accounting states are automatically excluded from the unknowns.

Residual operators only: direct HOC/characteristic updates and moment boundary events are unsupported. Callback autonomy is a user declaration, not inferred from numerical probes. Callbacks must be pure. Nonlinear iterates must remain in the representation's admissible domain; no clipping or closure repair is applied.

Use observe(observable, solution) to evaluate measurements at the root, and InferenceExperiment with timeless Measurement(data, observable) blocks for parameter estimation. StationarySolver supplies checked equilibrium solves and implicit sensitivities for smooth, isolated roots.

PopulationBalanceModels.axial_problem — Method
axial_problem(local_problem::StationaryPBMProblem, domain::AxialDispersion;
              guess=nothing, axial_scheme=Upwind(), residual_scale=1, constraints=())

Construct a coupled stationary axial problem without creating a transient time span. The local problem must contain a PBMSystem. By default repeat its physical guess in every axial cell; native histories remain excluded. The declared autonomy/frozen time applies to inlet conditions too. PopulationBalanceModels.solve_stationary — Method
solve_stationary(problem, [algorithm]; abstol=1e-9, reltol=0, maxiters=1000, ...)

Load NonlinearSolve. Default algorithm: RobustMultiNewton. The default uses finite-difference Jacobians for quadrature closures (whose inversion may not support dual numbers); other residuals retain the backend's AD default. An explicitly supplied algorithm controls its own differentiation backend. The selected physical closure is never changed. A converged backend retcode alone is insufficient: independently check admissibility, all scaled physical balances and constrained equations against abstol + reltol*r0, where r0 is the initial scaled/constrained infinity norm. A failed solve returns converged=false; invalid physical/closure evaluations raise an error rather than clipping. Scaling and admissible starting guesses are the user's choices. This does not establish uniqueness, stability, spatial accuracy or identifiability.

PopulationBalanceModels.stationary_residual! — Function
stationary_residual!(r, u, problem::StationaryPBMProblem, p=problem.p)

Assemble all physical mechanisms and bulk exchanges first, divide by declared rate scales, then replace explicitly constrained rows. Checks admissibility before evaluating rates/closures. Shapes match problem.guess. Neither the state nor the problem is mutated; callbacks must also avoid side effects.

PopulationBalanceModels.Inguva2022 — Type
Inguva2022()

Double-transformation method for homogeneous 1D transport with a positive autonomous AffineGrowth law (Inguva, Schickel & Braatz, 2022, §2.2.1, fourth approach). Select with compile(...; evolution=Inguva2022(),p). The physical mesh must be uniform in travel time. Bin-integrated numbers shift one cell per step; this is the conservative cell-integral version of the paper's nodal shift. It is not a new reconstruction for an arbitrary residual or an SSPRK step.

source
PopulationBalanceModels.InguvaBraatz2023 — Type
InguvaBraatz2023()

Commuting dimensional shifts after the double transformation for homogeneous 2D transport with SeparableGrowth2D (Inguva & Braatz, 2023, §2.2.1). Both axes must have the same travel-time spacing. Sources, collisions, bulk feedback, cross-coordinate growth and time-dependent laws are rejected, not split silently.

PopulationBalanceModels.characteristic_density — Method
characteristic_density(operator, initial_density, position, elapsed; p=(;))

Evaluate the continuous characteristic solution for an eligible compiled model. initial_density(a) (or (a₁,a₂)) supplies an actual continuous initial density; the velocity-ratio Jacobian converts it to the physical density at elapsed time. Zero inflow is imposed outside the initial physical domain; periodic constant growth wraps the foot. This evaluation needs no interpolation or CFL-aligned output time. The separate bin-shift solver DOES require aligned mesh/time steps. When fitting rate parameters, this continuous evaluator can reuse the structural compilation; a bin-shift run must rebuild its mesh for changed parameters.

PopulationBalanceModels.characteristic_grid — Method
characteristic_grid(law, bounds; dt, p=(;), coordinate=:length, endpoint=:extend)

Construct physical edges with constant travel-time increment dt. bounds is (lower,upper) for AffineGrowth, or a pair of bounds for SeparableGrowth2D. endpoint=:extend includes the requested domain and adds a whole last cell; :truncate omits a fractional last cell; :exact requires an aligned endpoint. Inspect the returned physical edges: no short final cell is inserted. Both axes of a 2D grid use the SAME dt, which gives CFL=1 in each split subproblem.

PopulationBalanceModels.HOCADI — Type

Compact fourth-order spatial derivative with alternating directional implicit Cayley solves. timeorder=2 is factorized Crank–Nicolson; timeorder=4 composes three symmetric steps (one negative substep). Restricted to homogeneous, constant-velocity transport on periodic uniform axes. This is a fully specified verified variant, NOT a transcription of Li et al. (2026), Eqs. 6–16.

PopulationBalanceModels.BeamWarming — Type
BeamWarming()

Second-order upwind space–time update for the same constant-growth class as LaxWendroff. This implementation restricts |g|dt/Δa ≤ 1. The first upstream interior face falls back to Upwind at nonperiodic boundaries. No limiter.

PopulationBalanceModels.LaxWendroff — Type
LaxWendroff()

Conservative second-order space–time update for homogeneous constant 1D growth on a uniform grid. Select compile(...; evolution=LaxWendroff()) with an explicit AffineGrowth(g,0). Not a reconstruction for an arbitrary RK residual. Requires |g|dt/Δa ≤ 1; oscillations and negative densities are possible.

PopulationBalanceModels.MeasureEuler — Type
MeasureEuler(; reconstruction=nothing, reconstruction_rtol=1e-7,
             cfl=0.9, event_rtol=1e-10, max_rejections=40)

Opt-in first-order positive-measure evolution. Growth pushes quadrature atoms along frozen-velocity characteristics; point births use positive age quadrature; removal and collision events use nonnegative forward-Euler measure updates under a depletion bound. Every physical substep is reconstructed and checked. Bulk exchanges use the same moment differences and escaped material. No moments are clipped or projected. ExactClosure requires an explicitly supplied RankAdaptiveQMOM reconstruction; QMOM and RankAdaptiveQMOM use their own rules. EQMOM, LogNormalClosure and DQMOM are not supported by this policy. Fixed QMOM cannot cross rank loss; use RankAdaptiveQMOM for extinction. Axial upwind/centered transport is a common positive mixture under a mesh-dependent CFL bound.

PopulationBalanceModels.simulate — Method
simulate(problem; dt, saveat=[t0,tf], check_nonnegative=true,
         negative_tolerance=1e-12, maxsteps=10^7)

Explicit fixed-step reference integrator (SSPRK33 by default). Select ForwardEuler(), SSPRK22(), SSPRK33(), SSPRK54(), or RK4(). dt is a maximum step; a step is shortened to land on each output time. No clipping, automatic grid change, or implicit stiffness treatment is performed. Choose dt using suggest_dt and check convergence. odeproblem connects compatible residuals to adaptive/stiff SciML solvers; the native admissibility policy does not transfer automatically.
