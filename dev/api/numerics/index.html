Numerical methods and compilation

TermMethods selects per-mechanism defaults and per-name overrides. compile checks compatibility and prepares the selected implementation for a grid or moment representation. Spatial residuals, moment closures and complete space–time updates have different contracts; a constructor alone does not establish that a combination is supported.

The method guide, moment guide and compact-method guide explain those restrictions. Public extension hooks are described in Contributing and internals.

For moment formulations, compile(model,basis; moment_method=QMOM()) infers the node count from the basis and automatically mixes analytical contributions with reconstruction where needed. moment_plan reports per-equation dependencies and missing moments. Legacy family aliases and explicit weak-form overrides remain available; see the moment workflow.

PopulationBalanceModels.AxialDispersion — Type
AxialDispersion(grid::AxialGrid; velocity, dispersion, inlet=nothing,
                boundary=:danckwerts)

Prescribed constant nonnegative axial velocity and dispersion coefficient. inlet(p,t) returns intrinsic-bin concentrations (not densities or fluxes). The Danckwerts total inlet flux is velocity*inlet; the outlet has zero dispersive flux. inlet=nothing means zero feed. :periodic is also supported; :closed requires zero velocity. State shape is (intrinsic bins, axial cells), including flattened Grid2D bins. No flow-field or bulk-balance solver is introduced.

PopulationBalanceModels.axial_problem — Method
axial_problem(local_problem, domain::AxialDispersion; initial=nothing,
              axial_scheme=Upwind())

Transport every population and scalar bulk balance of a local PBMSystem along an axial mesh. Local mechanisms and exchanges are evaluated simultaneously in each cell. The initial matrix has packed local states in rows and axial cells in columns; by default repeat localproblem.u0. domain.inlet(p,t) returns either that packed vector or `(populations=(name=binnumbers,...),bulk=(name=value,...))`. Danckwerts inlet fluxes and zero-gradient outlets apply to all components. Supports Grid1D/Grid2D sectional populations and raw moments, with residual-based methods. Direct quadrature states cannot be transported as if they were conserved raw moments and are rejected. Velocity and dispersion are prescribed, not solved.

PopulationBalanceModels.HOCFiniteVolume — Type
HOCFiniteVolume(; time_order=2)

Conservative compact transport of sectional bin integrals, in one or two coordinates. Fourth-order interior spatial reconstruction, midpoint time integration of order two, and symmetric directional/source composition. Select compile(model, grid; evolution=HOCFiniteVolume(), bc, p).

Requires uniform axes (at least six cells), positive declared growth laws, and periodic or physical inflow/outflow boundaries. Supports prescribed point nucleation. Unknown callbacks require HOCGrowthLaw / PrescribedRate contracts. No collisions, removal, axial transport, or evolving bulk coupling. This independently derived finite-volume adaptation is not the printed Zhang/Li nodal update. It has no positivity guarantee; the usual explicit nonnegativity check remains enabled. See Compact-method verification.

PopulationBalanceModels.compile — Method
compile(model, MomentSet(0:K); moment_method=nothing, fields=...)

Evaluate each supported contribution analytically from tracked moments, using the selected reconstruction only for missing moments or generic population integrals. QMOM() and other node-based specifications infer resolution from the basis. Without a keyword, closed supported models use ExactClosure; otherwise compatible bases use RankAdaptiveQMOM. Odd raw-moment counts never silently select an assumed density. Inspect moment_plan(operator).

moment_method=ExactClosure() strictly requires analytical evolution. Legacy method/closure aliases and explicit TermMethods overrides remain available; supply only one family keyword. Boundary events still require MeasureEuler.

source
PopulationBalanceModels.compile — Method
compile(model, grid; methods=TermMethods(), growth_scheme=Upwind(), bc=SizeBC(),
        domain=BatchDomain(), fields=(cell,t)->(;), evolution=nothing, p=(;))

Prepare a conservative sectional operator. Callback context contains grid, N (the local bin concentrations), cell, and fields (prescribed conditions). Methods select numerical treatment by mechanism class or individual term name. Named choices in methods.by_term take precedence over class choices. Collision deposition is evaluated during each residual call.

Alternatively, evolution=Inguva2022() compiles eligible homogeneous affine growth as a direct characteristic update. Supply p for named coefficients; the compiler checks the physical mesh, growth form and boundaries. Residual term methods cannot be combined with that complete transport update.

PopulationBalanceModels.suggest_dt — Method
suggest_dt(operator, state, p, t; cfl=0.5)

Local explicit Upwind/diffusion/loss step recommendation. Outgoing rates are added before taking the largest cell rate; uniform interior cells contribute abs(G)/ΔL + 2D/ΔL². Closed exterior diffusion faces are omitted. Coefficients use the supplied current state/context. This does not control simulate's dt, bound subsequent coefficient changes or guarantee positivity for arbitrary growth reconstructions. Check every RK stage and refine independently.

PopulationBalanceModels.EQMOM — Type
EQMOM([nodes]; kernel=:gamma, secondary_nodes=12, rtol=1e-7, maxiters=80)

One-coordinate Gamma extended QMOM using moments 0:2nodes. A mixture of nodes Gamma kernels has nonnegative means and a common scale (width) parameter. Moment deconvolution and a bracketed realizability-boundary search determine the width; all original moments must reconstruct before a result is accepted. Secondary Gauss–Laguerre quadrature integrates weak forms, independently of the primary inversion. Only the Gamma kernel is implemented. Not every realizable moment vector admits this kernel representation; failures are explicit.

source
PopulationBalanceModels.RankAdaptiveQMOM — Type
RankAdaptiveQMOM([max_nodes]; rtol=1e-8)

Evolve moments 0:2maxnodes-1 and use the smallest nonnegative quadrature that reconstructs ALL tracked moments to the requested scaled tolerance. The number of ODE states stays fixed. Singular point-mass and empty populations are allowed; unresolved/nonrealizable inputs are rejected, not projected onto another vector. quadrature reports rank and the scaled `momenterror`.

PopulationBalanceModels.reconstructed_bins — Method
reconstructed_bins(basis,state,method::EQMOM,edges; weight_order=0,normalize=false)

Exact Gamma-CDF bin integrals of the declared kernel mixture, optionally weighted by x^weight_order. Includes width-zero atoms, with left-closed bins and a closed final edge. Normalization conditions on the stated window. No particle sample count is invented, and QMOM nodes are not treated as a reconstructed density.

analytical_moment(term, order, getmoment, p, t, ctx)

Evaluate one declared analytical contribution. getmoment(k) supplies a tracked moment directly or a missing moment from the selected family. Extend this together with moment_dependencies; independent source moments must not use population quadrature. Coefficients use the current time and context.

PopulationBalanceModels.moment_dependencies — Method
moment_dependencies(term, order)

Analytical moment-rule extension hook. Return the tuple of raw-moment orders needed for this contribution, or nothing if no analytical expression is implemented. An empty tuple denotes an independent source or structural zero. Implement analytical_moment as well. Dependencies describe declarations, never incidental parameter values. Generic supported rates use population quadrature.

source
PopulationBalanceModels.moment_plan — Method
moment_plan(compiled)

Inspect moment compilation: the resolved family, state_layout, state_length, tracked orders, requires_closure, and each named term's per-equation treatment, dependencies and missing orders. Analytical evolution is reported independently of the selected reconstruction family. Family validation still applies even when every evolution contribution is analytical. Grid term_methods is unchanged.

PopulationBalanceModels.reconstructed_moment — Method
reconstructed_moment(method, basis, state, reconstruction, order)

Evaluate a missing raw moment using the selected moment family. Tracked orders are read directly by the compiler's moment view and never pass through this hook. The default integrates the family's prepared positive nodes/weights; Gamma EQMOM integrates its kernels analytically and lognormal uses its assumed distribution. External families with another reconstruction can extend this hook.

PopulationBalanceModels.supports_moment_integral — Method
supports_moment_integral(term, basis)

Declare availability of a reconstruction-based population integral. External terms also implement prepare_term(term, QuadratureMomentRule(), basis) and moment_term!. This is an implementation capability, not an assertion that an arbitrary callback has polynomial structure. Independent sources instead need their own source moments (MomentSource or a source-specific extension).

PopulationBalanceModels.DQMOM — Type
DQMOM([nodes]; condition_limit=1e12)

One-coordinate direct quadrature method of moments, evolving weights w and weighted abscissas q=w*x. Uses a scaled confluent Vandermonde solve to match moments 0:2nodes-1. Sources, growth, removal and collisions use the same weak forms as QMOM. Positive weights and distinct nonnegative nodes are required; empty populations and node collisions are rejected rather than regularized. The method is for batch/coupled local balances, not spatial DQMOM transport.

PopulationBalanceModels.FiniteVolumeDiffusion — Type
FiniteVolumeDiffusion()

Conservative centred flux q = -(Dᵣ*Nᵣ/wᵣ - Dₗ*Nₗ/wₗ)/(xᵣ-xₗ) for SizeDiffusion on fixed Grid1D meshes. On Grid2D, apply the same rule to each diagonal coefficient and density N[i,j]/(wx[i]*wy[j]), multiplying each face flux by its transverse width. Closed exterior faces have zero total flux; periodic faces use the wrapped centre distance. Second-order consistent on uniform and smoothly graded meshes; no such order is promised for arbitrary grading. This is a spatial residual, not an implicit time update or a filter.
