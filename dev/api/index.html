API reference

The constructors and lifecycle below connect the manual to the public interface. Arguments in callback signatures are physical parameters p, time t, and current stage context ctx. Read each method's restrictions in the linked manual.

Model and solve

Grid1D(edges; coordinate=:volume)
PBMModel(; named_terms...)
TermMethods(; by_term=NamedTuple(), mechanism_methods...)
compile(model, grid; methods=TermMethods(), bc=SizeBC(), growth_scheme=Upwind())
compile(model, MomentSet(0:K); method=ExactClosure(), methods=TermMethods(),
        boundary=MomentBoundary())
characteristic_grid(AffineGrowth(:g0,:g1),(0.0,1.4);dt,p)
compile(model, grid; evolution=Inguva2022(),p,bc)
PBMProblem(operator, initial, (t0,tf); p=NamedTuple())
simulate(problem; dt, saveat=[t0,tf], method=SSPRK33())
compile(model, grid; evolution=LaxWendroff(),bc)
compile(model, grid; evolution=HOCFiniteVolume(),bc,p)

    velocity=u,dispersion=D,inlet=(p,t)->feed_bins))

The displayed calls summarize valid argument shapes, rather than forming one standalone program. A complete first model is executed in the documentation build. solution.t and solution.u hold saved times and states; standalone 1D sectional and moment states have one column. Use density(grid,N), moment(grid,N,k), and term_methods(operator) to interpret what was stored and how it was computed.

Residual-based time methods are ForwardEuler, SSPRK22, SSPRK33, SSPRK54, and RK4. VanLeer and geometry-aware WENO3 support nonuniform 1D grids. Centered and LinearUpwind add unlimited uniform-grid 1D reconstructions. LaxWendroff and BeamWarming are complete constant-growth space–time updates; they require an eligible model compiled with evolution. HOCFiniteVolume() selects the complete conservative compact update. Declare growth with AffineGrowth, ExponentialGrowth, TimeScaledGrowth, or an explicit HOCGrowthLaw contract. Two-dimensional directional laws use SeparableGrowth2D; prescribed source/inflow callbacks use PrescribedRate. See Compact-method verification for exact signatures, boundary units, restrictions and cumulative number diagnostics. For axial states, axial_population(operator,u,cell) restores a local intrinsic view and axial_fluxes(operator,u,p,t) returns physical face fluxes. See Axially dispersed reactors for units and boundary contracts.

RankAdaptiveQMOM(N) evolves 2N raw moments with a checked variable-rank quadrature. EQMOM(N) evolves 2N+1 raw moments with a Gamma-kernel reconstruction; reconstructed_density and reconstructed_bins make that assumption explicit. DQMOM(N) evolves positive weights and weighted abscissas; initialize it with quadrature_state(method,nodes,weights). Read Moment methods for rank, conditioning and boundary limits.

Couple and observe

PBMSystem(populations; bulk_rhs, interactions, exchanges, fields, nonnegative_bulk, accounting) accepts a named tuple of compiled populations. Its problem adds named initial populations and bulk0; use stateview(problem,u) to obtain named views. Use population(problem,u,name), bulk(problem,u,name) and cumulative(problem,u,population,mechanism,property=:number) for packed states. accounting_rates(problem,u,p,t) returns a named tree of instantaneous rates. See Coupled systems for callback and exchange contracts. axial_problem(local_problem,reactor;axial_scheme=...) adds axial transport to local sectional/raw-moment systems, including every scalar bulk state. axial_stateview(problem,u,cell) exposes a named local state; population and bulk accessors return axial arrays. Direct moment states are rejected.

Observation(times,data,observable; sigma) or a fixed covariance block becomes part of Experiment(problem,observations...) and then CalibrationProblem(experiments; parameters,dt,solver). residuals, objective, and sensitivity_report use this shared forward model. fit(calibration,z0; ...) needs Optim; odeproblem(problem; ...) needs SciMLBase. predictions returns the observation matrices. fit_diagnostics assesses rank, residuals, and numerical sensitivity; confidence_ellipsoid and ellipse_points construct local joint regions. fit_multistart and profile_likelihood use the fitting backend for multiple starts and nuisance-parameter refits. See Parameter estimation for assumptions and examples.

New Bayesian calculations use ParameterSpec, explicitly coordinated Prior declarations, Measurement, InferenceExperiment, and EstimationProblem. fit(problem) performs MAP using Optim. loglikelihood, logprior, and logposterior share the density used by laplace_approximation and sample_posterior. Sampling requires both AdvancedHMC and MCMCDiagnosticTools. parameter_draws transforms draws, and posterior_predictive requires an explicit forward-solve budget. The Bayesian and legacy frequentist uncertainty APIs have different interpretations; see the estimation chapter. diagnostics(samples) exposes per-chain sampling reports, including BFMI, acceptance, step sizes, warmup statistics and Monte Carlo errors, alongside rank R-hat and bulk/tail ESS.

posterior_gradient and likelihood_gradient default to ForwardDiff. check_gradient compares against independent finite differences. Both inference problem constructors accept derivatives=:finite_difference when explicitly needed. SciMLSensitivitySolver(algorithm;sensitivity=:auto) enables optional continuous forward/adjoint ODE sensitivities; see the estimation chapter for dependencies and compatibility. TruncatedGaussianLikelihood(sigma=...) provides normalized independent nonnegative measurements.

Numerical extensions

A sectional policy supplies prepare_term(term,method,representation; kwargs...) and add_term!(du,u,term,method,cache,operator,p,t,ctx). A moment family additionally supplies state mapping, stage validation, reconstruction, and weak-form accumulation. See Development for full contracts and a working delegation example.

PopulationBalanceModels.DQMOM — Type
DQMOM(nodes; condition_limit=1e12)

One-coordinate direct quadrature method of moments, evolving weights w and weighted abscissas q=w*x. Uses a scaled confluent Vandermonde solve to match moments 0:2nodes-1. PopulationBalanceModels.DistributionObservable — Type
DistributionObservable(edges; coordinate, population=nothing, weight=x->1, normalize=false, response=nothing)

Integrate a sectional density over measurement bins, independently of solver bins. weight specifies number, volume or instrument intensity weighting. PopulationBalanceModels.EQMOM — Type
EQMOM(nodes; kernel=:gamma, secondary_nodes=12, rtol=1e-7, maxiters=80)

One-coordinate Gamma extended QMOM using moments 0:2nodes. A mixture of nodes Gamma kernels has nonnegative means and a common scale (width) parameter. Moment deconvolution and a bracketed realizability-boundary search determine the width; all original moments must reconstruct before a result is accepted. Secondary Gauss–Laguerre quadrature integrates weak forms, independently of the primary inversion. Only the Gamma kernel is implemented. Not every realizable moment vector admits this kernel representation; failures are explicit.

Shared statistical model for MAP, Laplace and sampling. All fitted nuisance parameters are included.

PopulationBalanceModels.Growth — Type

Conservative transport in the internal coordinate x, with PDE contribution $-\frac{\partial (Gn)}{\partial x}$. PopulationBalanceModels.HOCADI — Type

Compact fourth-order spatial derivative with alternating directional implicit Cayley solves. timeorder=2 is factorized Crank–Nicolson; timeorder=4 composes three symmetric steps (one negative substep). Restricted to homogeneous, constant-velocity transport on periodic uniform axes. This is a fully specified verified variant, NOT a transcription of Li et al. (2026), Eqs. 6–16.

source
PopulationBalanceModels.HOCFiniteVolume — Type
HOCFiniteVolume(; time_order=2)

Conservative compact transport of sectional bin integrals, in one or two coordinates. Fourth-order interior spatial reconstruction, midpoint time integration of order two, and symmetric directional/source composition. Select compile(model, grid; evolution=HOCFiniteVolume(), bc, p).

Requires uniform axes (at least six cells), positive declared growth laws, and periodic or physical inflow/outflow boundaries. Supports prescribed point nucleation. Unknown callbacks require HOCGrowthLaw / PrescribedRate contracts. No collisions, removal, axial transport, or evolving bulk coupling. This independently derived finite-volume adaptation is not the printed Zhang/Li nodal update. It has no positivity guarantee; the usual explicit nonnegativity check remains enabled. See Compact-method verification.

source
PopulationBalanceModels.HOCGrowthLaw — Type
HOCGrowthLaw(rate; lower_bound, dependencies=(:coordinate,:parameters), periodic=false)

Declare a smooth (C⁶), strictly positive directional law rate(x,p,t,ctx) for HOC. lower_bound(p,t,ctx) must be a positive lower bound on the entire compiled axis at that time. periodic=true additionally declares a smooth periodic extension, including derivatives. These assumptions are supplied by the user; sampling does not certify them. HOC checks the bound and every numerical face value on problem construction and every update. Allowed dependencies are the own :coordinate, :time, :parameters, and prescribed :fields.

PopulationBalanceModels.Inguva2022 — Type
Inguva2022()

Double-transformation method for homogeneous 1D transport with a positive autonomous AffineGrowth law (Inguva, Schickel & Braatz, 2022, §2.2.1, fourth approach). Select with compile(...; evolution=Inguva2022(),p). The physical mesh must be uniform in travel time. Bin-integrated numbers shift one cell per step; this is the conservative cell-integral version of the paper's nodal shift. It is not a new reconstruction for an arbitrary residual or an SSPRK step.

PopulationBalanceModels.MeasureEuler — Type
MeasureEuler(; reconstruction=nothing, reconstruction_rtol=1e-7,
             cfl=0.9, event_rtol=1e-10, max_rejections=40)

Opt-in first-order positive-measure evolution. Growth pushes quadrature atoms along frozen-velocity characteristics; point births use positive age quadrature; removal and collision events use nonnegative forward-Euler measure updates under a depletion bound. Every physical substep is reconstructed and checked. Bulk exchanges use the same moment differences and escaped material. No moments are clipped or projected. ExactClosure requires an explicitly supplied RankAdaptiveQMOM reconstruction; QMOM and RankAdaptiveQMOM use their own rules. EQMOM, LogNormalClosure and DQMOM are not supported by this policy. Fixed QMOM cannot cross rank loss; use RankAdaptiveQMOM for extinction. Axial upwind/centered transport is a common positive mixture under a mesh-dependent CFL bound.

PopulationBalanceModels.MomentBoundary — Type
MomentBoundary(; lower=0.0, upper=Inf, left=:error, right=:error)

Declared support and characteristic boundary treatment for MeasureEuler. :absorb is allowed only at physical zero on the left; :escape records removal at a finite computational edge; :error rejects a crossing. Atomic particles are removed at their hitting time, without inferring a continuum density trace. Residual-based moment solvers do not implement these boundary events.

PopulationBalanceModels.RankAdaptiveQMOM — Type

PopulationBalanceModels.check_sampling_map — Method
