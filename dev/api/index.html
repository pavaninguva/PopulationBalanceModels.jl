API reference

The constructors and lifecycle below connect the manual to the public interface. Arguments in callback signatures are physical parameters p, time t, and current stage context ctx. Read each method's restrictions in the linked manual.

Model and solve

Grid1D(edges; coordinate=:volume)
PBMModel(; named_terms...)
TermMethods(; by_term=NamedTuple(), mechanism_methods...)
compile(model, grid; methods=TermMethods(), bc=SizeBC(), growth_scheme=Upwind())
compile(model, MomentSet(0:K); method=ExactClosure(), methods=TermMethods())
PBMProblem(operator, initial, (t0,tf); p=NamedTuple())
simulate(problem; dt, saveat=[t0,tf], method=SSPRK33())

The displayed calls summarize valid argument shapes, rather than forming one standalone program. A complete first model is executed in the documentation build. solution.t and solution.u hold saved times and states; standalone 1D sectional and moment states have one column. Use density(grid,N), moment(grid,N,k), and term_methods(operator) to interpret what was stored and how it was computed.

Couple and observe

PBMSystem(populations; bulk_rhs, interactions, exchanges, fields, nonnegative_bulk) accepts a named tuple of compiled populations. Its problem adds named initial populations and bulk0; use stateview(problem,u) to obtain named views. See Coupled systems for callback and exchange contracts.

Observation(times,data,observable; sigma) becomes part of Experiment(problem,observations...) and then CalibrationProblem(experiments; parameters,dt). residuals, objective, and sensitivity_report use this shared forward model. fit(calibration,z0; ...) needs Optim; odeproblem(problem; ...) needs SciMLBase. See Observations and estimation for measurement semantics.

Numerical extensions

A sectional policy supplies prepare_term(term,method,representation; kwargs...) and add_term!(du,u,term,method,cache,operator,p,t,ctx). A moment family additionally supplies state mapping, stage validation, reconstruction, and weak-form accumulation. See Development for full contracts and a working delegation example.

PopulationBalanceModels.Breakage — Type
Breakage(rate, daughters; overflow=:error)

rate(v,p,t,ctx) is the parent hazard. daughters(v,p,t,ctx) returns an iterable of (daughter_size, expected_number) pairs, including quadrature weights if discretizing a continuous daughter distribution. PopulationBalanceModels.HOCADI — Type

Compact fourth-order spatial derivative with alternating directional implicit Cayley solves. timeorder=2 is factorized Crank–Nicolson; timeorder=4 composes three symmetric steps (one negative substep). PopulationBalanceModels.GaussianNucleation — Method
GaussianNucleation(rate; center, width, truncation=:renormalize)

One-dimensional Gaussian creation with bin-integrated weights. center and standard-deviation width are numbers or (p,t,ctx) callbacks. :renormalize creates the full rate on the finite domain; :physical retains only the physical Gaussian fraction inside that domain. Width is a physical model parameter, independent of grid spacing.

PopulationBalanceModels.compile — Method
compile(model, grid; growth_scheme=Upwind(), bc=SizeBC(),
        domain=BatchDomain(), fields=(cell,t)->(;))

Prepare a conservative sectional operator. Callback context contains grid, N (the local bin concentrations), cell, and fields (prescribed conditions). The reference implementation intentionally computes collision deposition on the fly; it is a correctness foundation, not an optimized large-scale CFD engine.

source
PopulationBalanceModels.compile — Method
compile(model, MomentSet(0:K); closure=ExactClosure(), fields=...)

Exact rules: polynomial growth/removal, constant-kernel aggregation in additive coordinates, self-similar polynomial-rate breakage, point creation, MomentSource. QMOM additionally evaluates general growth, removal, aggregation and breakage through their weak forms. It does not infer source integrals or boundary losses.

PopulationBalanceModels.realizability — Method

Necessary Stieltjes Hankel positivity diagnostics for raw moments. valid does not prove realizability at singular boundaries; QMOM also requires an invertible Hankel matrix and verifies its reconstructed moments.

source
PopulationBalanceModels.sensitivity_report — Method

Finite-difference residual Jacobian in optimization coordinates, its singular values and numerical rank. Local covariance is (J'J)^(-1) ONLY at full column rank. This is a local Gaussian approximation, not a confidence interval or structural-identifiability proof; use profiles/bootstrap/posteriors in a release.

source
PopulationBalanceModels.simulate — Method
simulate(problem; dt, saveat=[t0,tf], check_nonnegative=true,
         negative_tolerance=1e-12, maxsteps=10^7)

Explicit SSPRK(3,3) reference integrator. dt is a maximum fixed step; a step is shortened to land on each output time. No clipping, automatic grid change, or implicit stiffness treatment is performed. Choose dt using suggest_dt and check convergence. For production adaptive/stiff integration use odeproblem.

source
PopulationBalanceModels.suggest_dt — Method

Conservative heuristic step bound for explicit Upwind/source updates. WENO5 and CustomTerm have no positivity guarantee from this bound. Check every RK stage.

source

The selected method for every named term, useful for reproducible run records.
