API reference

Choose a topic below, or use the symbol index. Reference pages contain constructor and operation docstrings; the manual chapters explain how to assemble a complete calculation. Start with the first model, first MAP fit or first UQ calculation.

Model and solve

  • Models and representations: physical terms, rate laws, grids, moment bases, boundary conditions and model declarations.
  • Numerical methods and compilation: term discretization, reconstructions, moment methods, compatibility checks and prepared operators.
  • Problems, solvers and integrations: transient and stationary problems, time integration, root solving, continuation and solver entry points.

Couple and observe

  • Coupling and accounting: named populations, bulk balances, interactions, state accessors and cumulative accounting.
  • Observations and discrepancies: measurement operators, conditional CDFs/quantiles and deterministic comparison blocks.

Parameter estimation

Estimation interfaces cover parameters, priors, likelihoods, MAP diagnostics, uncertainty, derivatives, profiles and posterior sampling. Bayesian and legacy frequentist/discrepancy interfaces retain their distinct statistical meanings; see the estimation guide.

Forward uncertainty quantification

UQ interfaces cover uncertain inputs, forward scenarios, MC propagation, PCE construction/evaluation and summaries. The UQ guide develops a complete data-free calculation.

Numerical extensions

Public extension hooks are documented with their representations, numerical methods and coupling interfaces. The developer guide explains their dispatch and validation contracts.
