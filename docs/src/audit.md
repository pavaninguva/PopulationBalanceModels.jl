verification. Passing a test establishes its stated configuration; it does not
certify every closure, callback, numerical resolution or physical model.

## Inventory and supported contracts

The API build checks exports. Source separates physical declarations,
representations, per-term policies, compilation, coupling, native integration
and inference. Four extensions implement Optim, SciMLBase,
SciMLSensitivity/ReverseDiff and AdvancedHMC/MCMCDiagnosticTools. Distributions,
ForwardDiff and SpecialFunctions are runtime dependencies; Aqua and JET remain
development tools. `fit` and `loglikelihood` share upstream generic bindings.
PBM raw `moment` retains its distinct meaning; use selective Distributions
imports to avoid its exported sample-moment name.

| Configuration | Supported behavior | Limits checked or retained |
|:--|:--|:--|
| 1D sectional | Integrated bin number/process volume; signed growth, point/boundary/distributed births, removal, fixed-pivot collisions | Density=N/ΔL. Center-weighted moments define the discrete invariant. Products use additive-property deposition; no other aggregation algorithms implemented. |
| Sectional growth | Upwind, MUSCL, van Leer, WENO3; uniform WENO5, centered and linear upwind | Per-term/grid eligibility checked. WENO/unlimited methods do not imply positivity. Lax–Wendroff/Beam–Warming are restricted space–time policies. |
| Tensor distributions | Two-coordinate growth, point/distributed births and removal | Upwind/uniform WENO5; transverse-width fluxes. No tensor aggregation/breakage. |
| Trajectory methods | Eligible structured 1D/2D growth on travel-time meshes; exact constant shifts | CFL/output alignment and autonomous/separable laws checked. No arbitrary growth, bulk coupling or hidden interpolation. HOCADI is a periodic constant-growth variant, not Li2026 reproduction. |
| Raw moments | Dependency-closed exact laws; QMOM, rank-adaptive QMOM, Gamma EQMOM, assumed lognormal weak forms | Realizability, closure representability, integration quadrature and evolution accuracy differ. Continuous daughter integrals use `daughter_moment` where supplied. |
| DQMOM | Positive distinct weights/weighted abscissas; scaled source solves and moment chain-rule exchange | Not raw-moment layout; no empty startup, node collision or extinction treatment. |
| MeasureEuler batch | Positive pushforward, age-integrated point births, bounded removal/collisions, shared-bulk Lie composition | First order. Upwind sectionals or supported raw QMOM/rank-adaptive states; ExactClosure needs explicit reconstruction. All-moment reduction, depletion/CFL and transactional retries. EQMOM/lognormal/DQMOM and custom interactions rejected. |
| Removal/accounting | Zero absorption, positive-cutoff and upper escape, collision/discarded-source losses | Atomic hitting differs from sectional trace. Escaped material is not dissolved twice; reconstruction defect stays separate. Historical ledgers have no subsequent kinetics. |
| Axial systems | Nonuniform conservative fluxes, prescribed advection/dispersion, Danckwerts/periodic/closed boundaries | Upwind positive common-mixture raw-moment guarantee under CFL. Independent high-order moment limiting and simultaneous size events excluded. Reactor flux integrals differ from stationary size-loss histories. |
| Shared balances | Current-stage bulk/population laws; transfers and cross aggregation | Selected residual supplies exchange. Fixed conversion factors define invariants; changing density/process volume needs its own balance. Interactions outside MeasureEuler. |
| Inference | Shared/local/fixed/nuisance parameters, normalized likelihoods, declared prior coordinates, AD/default or optional continuous sensitivities | Actual posterior Hessian and full nuisance covariance for checked Laplace. No event/rank-changing sensitivities. Fractions do not acquire invented counts; derived moments are not independent duplicate data. |
| External ODE solvers | Compatible residuals through SciML | Native MeasureEuler guarantees/atomic events do not transfer. Callback purity and solver/representation differentiability remain requirements. |

Independent tests cover identical-pair factors, parent/daughter event and
property rates, source normalization, signed boundary fluxes, DQMOM chain
rules, unit rescaling and support rejection. Existing checks independently vary
timestep, rank, source/daughter quadrature and axial mesh where stated. Qamar's
reference grid also sets a split timestep: that difference combines spatial and
splitting errors. Necessary Hankel checks are not a singular moment certificate.

guarantees or revised paper-benchmark timings.

## Compatibility notes

Model/representation constructors retain their names. Accounting adds
`:nucleation_underflow` and `:nucleation_overflow`, changing packed lengths and
offsets: use `population`, `bulk` and `cumulative`. Previously accepted RK
outputs can now reject an unresolved closure. Invalid fractions and comparisons
that change noise fail explicitly. Native diagnostics name the actual policy.
`check_sampling_map` is additive; tuning, starts, returned draws and energies
retain documented coordinate conventions.

No runtime dependency was added. Aqua 0.8 is test-only; JET 0.12 lives in an
isolated CI job. Older optional major versions allowed by compat were not
exhaustively resolved: current/maintained stacks and minimum core runtime are
the executed evidence.
